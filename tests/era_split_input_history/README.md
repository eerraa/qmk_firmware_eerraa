# Split input production fixtures

Run `python3 -m unittest discover -s tests/era_split_input_history -p 'test_*.py'`
from the synchronized WSL build tree. The native compiler runs the production
input owners, codec, initiator and responder with TOMAK geometry. Focused
extracted production functions execute USB admission, PIO lease call order,
action admission and the tapping FIFO's direct tail paths. Mocks supply clocks,
hardware calls and unrelated owners; they do not implement input history.

`make test:era_split_input_qmk` runs actual QMK action/tapping and ERA Tap Dance
through a recording HID owner. Its finite profiles count generated reports and
accepted posts, including NKRO and widths. The existing report interval,
standing, restart and link lifecycle targets cover their own production owners.

These fixtures establish firmware ordering, identity, admission, lifetime,
quota and report ownership. They do not establish physical PIO termination,
electrical margins, USB IN timing, original cross-half global timing, measured
scan latency or maximum device QMK pass duration.
