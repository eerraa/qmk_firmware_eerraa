======================================================================
Official VIA Guide
======================================================================

이 문서는 공식 VIA(https://usevia.app)를 직접 사용하는 경우의 안내입니다.
일반 사용자는 https://usekb.cc 를 권장합니다. usekb.cc에서는 각 메뉴 옆 Help로
같은 기능을 바로 확인할 수 있습니다.

----------------------------------------------------------------------
한국어
----------------------------------------------------------------------

스톡 VIA는 기본 설정을 지원합니다. 복잡한 고급 편집과 자동 갱신 상태 표시는
usekb.cc Custom 앱에서 지원합니다.

■ 공식 VIA 시작

이 릴리스와 같은 메이커·보드 ZIP에 동봉된 JSON을 사용하십시오.
이전 USB 식별자 0x4552용 JSON은 새 메이커 식별자와 맞지 않습니다.

1. https://usevia.app 에 접속합니다.
2. SETTINGS에서 Show Design tab을 켭니다.
3. DESIGN -> Load Draft Definition에서 이 키보드의 VIA JSON을 불러옵니다.
4. CONFIGURE에서 KEYMAP, LIGHTING, FEATURE, TAPDANCE, SYSTEM을 설정합니다.

TAPDANCE 입력창에 직접 keycode를 넣을 때는 같은 폴더의 via_keycodes.txt를
참고하십시오. 키맵을 보관하려면 VIA의 SAVE + LOAD에서 백업하십시오.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION은 이 키보드의 펌웨어 버전을 YYMMDDRn 형식으로
표시합니다. 연·월·일과 리비전을 키보드에서 읽어 오는 값이며 VIA에서 수정할 수
없습니다. 문제를 제보할 때 이 값을 함께 적어 두면 좋습니다.

■ MATRIX TEST

260916R1 이후의 VIA 펌웨어는 VIA의 Matrix Test에서 물리 매트릭스 눌림을
표시합니다. 이 기능을 위해 VIA Raw HID를 사용할 수 있는 호스트 프로그램은 현재
눌린 매트릭스 위치를 조회할 수 있습니다. 신뢰할 수 있는 PC에서 사용하십시오.

■ TAPDANCE

CONFIGURE -> TAPDANCE에서 TD0~TD7을 설정한 뒤 KEYMAP에서 같은 TD 번호를
원하는 위치에 배치합니다. TD 키를 실제 키맵에 배치하기 전에는 설정한 동작이
실행되지 않습니다.

- On Tap: 짧게 탭했을 때의 keycode
- On Hold: 길게 눌렀을 때의 keycode
- On Double Tap: Term 안에 두 번 탭했을 때의 keycode
- Tap+Hold: 한 번 탭한 뒤 이어서 길게 눌렀을 때의 keycode
- Term: 어느 동작인지 판단하기까지 기다리는 시간(ms)

Legacy에서 On Double Tap과 Tap+Hold를 비워 둔 슬롯은 키를 떼는 순간 탭이 입력되고,
Term은 홀드 판정에만 쓰입니다. On Double Tap을 설정하면 두 번째 탭을 떼는
순간 입력됩니다.

공식 VIA에서는 Legacy 모드의 기본 동작과 Term만 편집합니다. 고급 모드의 슬롯은
usekb.cc 안내만 표시합니다. 알 수 없는 모드값에도 같은 안내를 표시하며,
이 상태에서는 기본 동작도 편집하지 않습니다.

입력 모드 변경, 독립 홀드 시간과 다른 키 누름 시 홀드 설정은 https://usekb.cc 의
Custom 앱에서 사용하십시오. 공식 VIA를 열거나 정의를 불러오는 것만으로 슬롯의
모드나 동작을 바꾸지는 않습니다.

■ SOCD

CONFIGURE -> FEATURE -> SOCD에서 서로 반대되는 두 키(좌/우, 상/하)를 지정하고,
두 키를 함께 누르고 있을 때 PC로 보낼 키를 Mode에서 고릅니다.

- Last Input: 나중에 누른 키만 보냅니다. 그 키를 떼면 아직 누르고 있는 다른
  키가 곧바로 다시 입력됩니다(스냅 탭). 기본값입니다.
- Neutral: 두 키 모두 보내지 않습니다.
- First Input: 먼저 누른 키를 유지합니다.
- Left/Up Priority, Right/Down Priority: 누른 순서와 상관없이 지정한 쪽을
  보냅니다.

키에는 일반 키나 modifier 키를 지정하십시오. 판정은 PC로 나가는 키를 기준으로
하므로 Tap Dance나 매크로가 낸 키에도 적용됩니다. 한 쌍의 두 칸에 같은 키를
넣거나 한 키를 두 쌍에 함께 넣으면 그 쌍은 동작하지 않습니다. 일부 게임과 대회는 SOCD 사용을 제한하므로 규정을
확인하십시오.

■ KKUK

CONFIGURE -> FEATURE -> KKUK에서 사용합니다. 일반 키 두 개 이상을 계속 누르면
눌린 키 묶음을 Delay/Repeat 설정에 따라 주기적으로 뗐다가 다시 누릅니다.
예를 들어 A, S, D를 계속 누르면 일반적인 "asdddd..." 자동 반복 대신 보통
"asdasdasd..."처럼 입력됩니다. 문자열 매크로나 매트릭스 ghosting 방지 기능이
아니며 SOCD에 지정한 키는 반복 대상에서 제외됩니다.

■ DEBOUNCE

CONFIGURE -> FEATURE -> DEBOUNCE에서 스위치 채터링 필터를 조정합니다.
기본값은 Balanced, 5 ms입니다. 한 번 눌렀는데 여러 번 입력되는 증상이 있다면
관련 시간을 조금씩 늘리십시오. 채터링 문제가 없다면 기본 설정을 유지하는 것을
권장합니다.

■ TAPPING

CONFIGURE -> FEATURE -> TAPPING에서 Mod-Tap/Layer-Tap의 탭·홀드 판정을
조정합니다. Tapping Term의 기본값은 200 ms입니다. 짧을수록 홀드가 빨리
걸리지만 빠른 타이핑이 의도치 않은 홀드로 판정될 수 있고, 길수록 안정적이지만
홀드가 늦게 들어옵니다.

- Permissive Hold: 다른 키를 눌렀다 뗄 때까지 탭·홀드 키를 계속 누르고 있으면
  홀드로 판정합니다.
- Hold On Other Key Press: 다른 키를 누르는 순간 바로 홀드로 판정합니다.
  더 빠르지만 굴려 치는 타건에서는 의도한 탭이 홀드가 될 수 있습니다.
- Retro Tapping: Term을 넘겨 눌렀더라도 그 사이 다른 키를 누르지 않았다면
  키를 뗄 때 탭을 입력합니다.

■ MOUSE

V261004R1부터 정수 단위 정밀 입력은 usekb.cc의 고급 설정에서 제공합니다.
스톡 VIA는 가장 가까운 프리셋을 표시하며 조회만으로 정밀 값을 바꾸지 않습니다.
휠 가속은 시간이 0이면 Off, 나머지는 목표 속도 기준으로 Mild/Strong을 표시합니다.
프리셋을 선택하면 그 설정으로 변경됩니다.

CONFIGURE -> FEATURE -> MOUSE에서 키보드의 Mouse Key 동작을 조정합니다.
키맵에 Mouse Key가 없으면 이 설정은 입력에 영향을 주지 않습니다. 값들이 서로
영향을 주므로 한 번에 하나씩 조정하는 것을 권장합니다.

- Cursor Acceleration: 시작 속도에서 최고 속도까지 가속하는 시간. Off면 고정 속도.
- Cursor Start Speed / Top Speed: 가속 시작/종료 시 한 스텝 이동 거리.
- Cursor Speed: Acceleration이 Off일 때 한 스텝 이동 거리.
- Cursor Steps Per Second: 초당 커서 이동 스텝 수.
- Wheel Rate: 초당 스크롤 스텝 수.
- Wheel Acceleration: 누르고 있는 동안 스크롤 가속 정도.

■ ROLLOVER / NKRO

CONFIGURE -> FEATURE -> NKRO에서 NKRO를 켜고 끕니다. 기본값은 꺼짐(6KRO)이고,
켜면 누른 키를 모두 보고합니다. 켠 뒤 오래된 BIOS/KVM이나 부팅 메뉴가
키보드를 읽지 못하면 다시 끄십시오.

■ LIGHTING

CONFIGURE -> LIGHTING에는 키보드가 실제 지원하는 조명 메뉴만 표시됩니다.
메뉴 이름은 LED가 있는 곳을 따릅니다: Per-Key RGB(키별 RGB), Underglow,
Backlight, Badge, Riley의 RGB LEDs. 잠금 상태 표시는 Indicators에서
설정합니다.

Backlight Pulse를 지원하는 보드의 효과 이름은 다음과 같습니다.

- Steady
- Breathing
- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Breathing을 선택하면 Breathing Period(1~10)로 숨쉬기 주기를 조절합니다.
값이 작을수록 빠릅니다. Pulse Speed는 Pulse에서만 표시되며 펄스 길이는
5 + 값 ms입니다. 0은 5 ms, 255는 260 ms이고 기본값 15는 20 ms입니다.
Hold 효과는 펄스 시간이 끝나도 해당 모드에서 눌린 키가 남아 있으면 유지됩니다.

RGBLight 조명(Underglow, Badge, RGB LEDs)은 Effect 목록의 Twinkle 6 뒤에
같은 Pulse 효과 네 가지가 있습니다. Effect Speed는 이 네 효과에서만 표시되며
위와 같은 펄스 길이를 조절합니다. 일반 Breathing 1~4 등의 속도는 Effect의
번호로 선택하고, 지원 효과에서는 Velocikey로 입력 속도에 반응하게 할 수 있습니다.

- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

7B75의 백라이트 레일은 두 잠금 표시등(기본 Caps Lock, Scroll Lock)만
켭니다. 그래서 Indicators에서 Indicator Brightness와 위 여섯 효과(Indicator
Effect)를, Badge에서 아크릴 배지의 RGB 효과/밝기/색/속도를 설정합니다.

Indicators는 Caps/Scroll/Num Lock 상태 표시입니다. 표시할 상태는
Indicator(여러 개면 Indicator 1, 2 …)에서 고릅니다. 0번 값은 표시 LED를
RGB 효과와 함께 쓰는 보드에서는 RGB Effect(효과가 그대로 보임), 전용 LED
보드에서는 Off입니다. 색은 사용자가 정하며, 스플릿 TOMAK의 링크·동기화
STATUS 색상표를 논스플릿 키보드에 적용하지 않습니다.

Riley에는 RGB LEDs와 Indicators 메뉴가 있습니다. RGB1/2/3은 Indicator
1/2/3에 대응합니다. 각 Indicator는 다음 중 하나입니다.

- RGB Effect
- Caps Lock
- Scroll Lock
- Num Lock

RGB Effect를 고른 LED는 일반 RGB 효과에 계속 참여합니다. Lock을 고른 LED는
해당 Lock이 켜졌을 때 그 Indicator의 Brightness와 Color를 사용합니다.
Indicator-Only를 켜면 Lock이 꺼진 표시 LED는 어두워지고, RGB Effect LED는
계속 RGB 효과를 표시합니다. Brightness/Color는 Indicator 1/2/3마다
독립적으로 설정합니다.

■ SYSTEM

SYSTEM -> SLEEP에서 RGB와 백라이트의 자동 절전을 따로 설정합니다. 키보드에
있는 조명의 항목만 표시됩니다.

- RGB Sleep, Backlight Sleep: 기본값은 On입니다. Off로 바꾸면 그 조명은 유휴
  시간, USB 절전, 호스트 소실 어느 경우에도 꺼지지 않습니다.
- RGB Sleep Timeout, Backlight Sleep Timeout: 해당 절전이 On일 때만 보이며,
  마지막 입력 뒤 1/3/5/10/30/60분 중 고릅니다. 기본값은 10분이고 토글을 꺼도
  값은 보존됩니다.

절전은 조명 출력만 끄고 설정은 바꾸지 않습니다. 입력이나 정상적인 호스트
복귀로 다시 켜지지만, 사용자가 끈 조명을 자동으로 켜지는 않습니다. 백라이트가
잠금 표시등을 겸하는 키보드는 백라이트 절전 중 표시등도 꺼집니다.

SYSTEM -> BOOT의 Jump To BOOT는 켜는 즉시 부트로더로 진입합니다. 실행 후
토글이 항상 꺼진 값으로 보이는 것이 정상입니다.

■ EEPROM CLEAN

기존 배포 펌웨어에는 10초 확인 제한이 남아 있습니다. 해당 버전에서는 세 토글을
10초 안에 모두 켜십시오. 시간 제한 제거는 새 펌웨어 설치 후 적용됩니다.

CONFIGURE -> SYSTEM -> EEPROM에서 세 확인 토글을 모두 켜면
저장된 키맵과 모든 설정을 초기화하고 재시작합니다. 실행 전 VIA SAVE + LOAD로 키맵을 백업하십시오.


----------------------------------------------------------------------
English
----------------------------------------------------------------------

Stock VIA supports basic configuration. Use the Custom app at usekb.cc for
advanced editing and automatically refreshed status.

■ Starting Official VIA

Use the JSON bundled with this release for the same maker and board.
An older JSON for USB vendor ID 0x4552 does not match the new maker identity.

1. Open https://usevia.app.
2. Enable Show Design tab in SETTINGS.
3. In DESIGN -> Load Draft Definition, load the VIA JSON for this keyboard.
4. Use CONFIGURE for KEYMAP, LIGHTING, FEATURE, TAPDANCE, and SYSTEM.

See via_keycodes.txt in the same folder when entering keycodes directly into
TAPDANCE fields. Use VIA SAVE + LOAD to back up a keymap you want to keep.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION shows this keyboard's firmware version in
YYMMDDRn form. The year, month, day, and revision are read from the keyboard and
cannot be changed in VIA. Include this value when reporting a problem.

■ MATRIX TEST

VIA firmware from 260916R1 onward reports physical matrix presses to VIA Matrix
Test. A host program with access to VIA Raw HID can therefore query currently
pressed matrix positions. Use the keyboard with trusted host software.

■ TAPDANCE

Configure TD0 through TD7 in CONFIGURE -> TAPDANCE, then place the matching
TD number on the desired key in KEYMAP. The configured actions do nothing until
that TD key is actually placed somewhere you can press it.

- On Tap: keycode for a short tap
- On Hold: keycode for a held press
- On Double Tap: keycode for two taps inside Term
- Tap+Hold: keycode for a tap followed by a hold
- Term: how long the keyboard waits before deciding the action, in milliseconds

In Legacy mode, a slot with On Double Tap and Tap+Hold left empty sends the tap the moment
the key is released, and Term then decides only the hold. With On Double
Tap set, the second tap is sent the moment it is released.

Official VIA edits only the basic actions and Term of slots in Legacy mode.
Advanced and unknown-mode slots show only the usekb.cc guidance.
Basic actions are also read-only in these states.

Use the Custom app at https://usekb.cc to change input mode, independent hold
time or hold-on-other-key settings. Opening official VIA or loading a
definition does not change a slot's mode or
configured actions.

■ SOCD

Assign each opposing key pair (left/right, up/down) in CONFIGURE -> FEATURE ->
SOCD, then choose in Mode what reaches the computer while both keys are held.

- Last Input: only the key pressed later is sent. Releasing it sends the key
  still held again at once (snap tap). This is the default.
- Neutral: neither key is sent.
- First Input: the key pressed first stays.
- Left/Up Priority, Right/Down Priority: the chosen side is sent regardless of
  press order.

Use ordinary keyboard or modifier keycodes. SOCD judges the keys going to the
computer, so it also applies to keys sent by Tap Dance or a macro. A pair with
the same key in both slots, or a key used in both pairs, does nothing. Some games and tournaments restrict SOCD; check their
rules.

■ KKUK

Use CONFIGURE -> FEATURE -> KKUK. While two or more ordinary keys remain held,
KKUK periodically releases the held group and presses it again according to
Delay/Repeat. For example, holding A, S, and D usually produces "asdasdasd..."
instead of the ordinary "asdddd..." auto-repeat. This is neither a string macro
nor matrix ghosting prevention. Keys assigned to SOCD are excluded.

■ DEBOUNCE

Adjust switch-chatter filtering in CONFIGURE -> FEATURE -> DEBOUNCE. The
default is Balanced, 5 ms. If one physical press sometimes produces multiple
inputs, increase the relevant delay a little at a time. If there is no chatter,
keeping the default settings is recommended.

■ TAPPING

Adjust Mod-Tap/Layer-Tap tap-hold decisions in CONFIGURE -> FEATURE -> TAPPING.
The default Tapping Term is 200 ms. Shorter makes holds trigger sooner but can
turn fast typing into accidental holds; longer is safer but makes the hold
arrive later.

- Permissive Hold: while the tap-hold key is still held, pressing and releasing
  another key makes it a hold.
- Hold On Other Key Press: another key press makes it a hold immediately. This
  is earlier, but rolling key presses can turn intended taps into holds.
- Retro Tapping: if the key is held past Term and released without another key
  press, the release still sends the tap.

■ MOUSE

From V261004R1, integer precision is available through Advanced settings at usekb.cc.
Stock VIA displays the nearest preset; reads never change precise settings.
Wheel acceleration shows Off for zero ramp, otherwise Mild/Strong by the nearest
target speed, ignoring duration (ties choose Mild). Selecting a preset writes it.

Configure Mouse Keys in CONFIGURE -> FEATURE -> MOUSE. These settings do not
affect typing unless Mouse Key keycodes are present in the keymap. The values
affect one another, so adjusting one at a time is recommended.

- Cursor Acceleration: time from start speed to top speed; Off uses fixed speed.
- Cursor Start Speed / Top Speed: distance per step at start/end of acceleration.
- Cursor Speed: distance per step while Acceleration is Off.
- Cursor Steps Per Second: cursor movement steps per second.
- Wheel Rate: scroll steps per second.
- Wheel Acceleration: how strongly scrolling accelerates while held.

■ ROLLOVER / NKRO

Turn NKRO on or off in CONFIGURE -> FEATURE -> NKRO. It is off by default
(6KRO); turned on, every held key is reported. If an old BIOS, KVM or boot menu
then cannot read the keyboard, turn it off again.

■ LIGHTING

CONFIGURE -> LIGHTING shows only the lighting surfaces supported by the board.
Menus are named for where the LEDs are: Per-Key RGB, Underglow, Backlight,
Badge, and Riley's RGB LEDs. Lock indication is set in Indicators.

Boards with Backlight Pulse use these effect names:

- Steady
- Breathing
- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Breathing exposes Breathing Period (1–10); smaller values mean faster breaths.
Pulse Speed appears only for Pulse effects. Duration is 5 + value ms: 0 is
5 ms, 255 is 260 ms, and the default 15 is 20 ms. Hold effects remain active
after that duration while keys pressed in the current mode remain held.

RGBLight lighting (Underglow, Badge, RGB LEDs) lists the same four Pulse
effects after Twinkle 6 in the Effect dropdown. Effect Speed appears only for these four
effects and controls the same pulse duration. For ordinary effects such as
Breathing 1–4, choose the numbered Effect variant. Supported effects can also
use Velocikey to react to typing speed.

- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

The 7B75 backlight rail lights only its two lock indicators (Caps Lock and
Scroll Lock by default), so Indicators holds Indicator Brightness and the six
effects above (Indicator Effect), and Badge holds the acrylic badge's RGB
effect, brightness, colour, and speed.

Indicators shows Caps/Scroll/Num Lock using the chosen colours; Indicator
(Indicator 1, 2, … on boards with several) chooses the lock. Value 0 is RGB
Effect where the indicator LED also shows the RGB effect, and Off on a
dedicated LED. The split TOMAK link/synchronization STATUS colour meanings do
not apply to non-split keyboards.

Riley has RGB LEDs plus Indicators. RGB1/2/3 map to Indicator 1/2/3. Each
Indicator is one of:

- RGB Effect
- Caps Lock
- Scroll Lock
- Num Lock

RGB Effect leaves that LED in the normal RGB animation. A Lock uses that
Indicator's Brightness and Color while the selected Lock is on. With
Indicator-Only enabled, an inactive lock-indicator LED goes dark while an RGB
Effect LED continues the RGB effect. Brightness/Color are independent for
Indicator 1, 2, and 3.

■ SYSTEM

SYSTEM -> SLEEP sets automatic sleep for RGB and backlight separately. Only the
lighting the keyboard has is listed.

- RGB Sleep, Backlight Sleep: on by default. Turned off, that lighting never
  sleeps on idle timeout, USB suspend or host loss.
- RGB Sleep Timeout, Backlight Sleep Timeout: shown only while that sleep is
  on. Choose 1/3/5/10/30/60 minutes of inactivity; the default is 10 minutes,
  and turning the toggle off keeps the value.

Sleep turns off only the lighting output and changes no setting. Input or a
normal host return wakes it, but lighting the user turned off stays off. On a
keyboard whose backlight also powers its lock indicators, backlight sleep turns
those indicators off too.

SYSTEM -> BOOT -> Jump To BOOT enters the bootloader as soon as it is switched
on. The toggle normally reads back off after the action.

■ EEPROM CLEAN

Existing release firmware still has a ten-second confirmation limit: turn on
all three toggles within ten seconds. Removing that limit requires installing
updated firmware.

Turn on all three confirmation toggles in CONFIGURE -> SYSTEM -> EEPROM
to erase the stored keymap and every setting and restart the
keyboard. Back up the keymap with VIA SAVE + LOAD before running CLEAN.
