======================================================================
EERRAA Split Official VIA Guide
======================================================================

이 문서는 공식 VIA(https://usevia.app)를 직접 사용하는 경우의 안내입니다.
일반 사용자는 https://usekb.cc 를 권장합니다. usekb.cc에서는 각 메뉴 옆 Help로
같은 기능을 바로 확인할 수 있습니다.

----------------------------------------------------------------------
한국어
----------------------------------------------------------------------

■ 공식 VIA 시작

1. https://usevia.app 에 접속합니다.
2. SETTINGS에서 Show Design tab을 켭니다.
3. DESIGN -> Load Draft Definition에서 현재 USB에 연결할 유닛의 VIA JSON을
   불러옵니다. L 파일은 왼쪽 유닛, R 파일은 오른쪽 유닛용입니다.
4. DUAL-HOST로 양쪽 유닛을 각각 USB에 연결한다면 L/R 두 JSON을 모두
   불러옵니다.
5. CONFIGURE에서 KEYMAP, LIGHTING, FEATURE, TAPDANCE, SYSTEM을 설정합니다.

TAPDANCE 입력창에 직접 keycode를 넣을 때는 같은 폴더의 via_keycodes.txt를
참고하십시오. 키맵을 보관하려면 VIA의 SAVE + LOAD에서 백업하십시오.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION은 현재 USB로 연결한 유닛의 펌웨어 버전을
YYMMDDRn 형식으로 표시합니다. 연·월·일과 리비전을 유닛에서 읽어 오는 값이며
VIA에서 수정할 수 없습니다. 양쪽 유닛은 같은 버전을 사용해야 합니다.

■ TAPDANCE

CONFIGURE -> TAPDANCE에서 TD0~TD7을 설정한 뒤 KEYMAP에서 같은 TD 번호를
원하는 위치에 배치합니다. TD 키를 실제 키맵에 배치하기 전에는 설정한 동작이
실행되지 않습니다.

- On Tap: 짧게 탭했을 때의 keycode
- On Hold: 길게 눌렀을 때의 keycode
- On Double Tap: Term 안에 두 번 탭했을 때의 keycode
- Tap+Hold: 한 번 탭한 뒤 이어서 길게 눌렀을 때의 keycode
- Term: 어느 동작인지 판단하기까지 기다리는 시간(ms)

■ SOCD

CONFIGURE -> FEATURE -> SOCD에서 서로 반대되는 두 키의 조합을 지정합니다.
두 키를 함께 누르고 있는 동안 나중에 누른 키가 우선합니다. 그 키를 떼면 먼저
누르고 있던 키가 아직 물리적으로 눌려 있는 경우 다시 활성화됩니다. 방향 충돌을
명확하게 처리해야 할 때 주로 사용합니다.

■ KKUK

CONFIGURE -> FEATURE -> KKUK에서 사용합니다. 일반 키 두 개 이상을 계속 누르면
눌린 키 묶음을 Delay/Repeat 설정에 따라 주기적으로 뗐다가 다시 누릅니다.
예를 들어 A, S, D를 계속 누르면 일반적인 "asdddd..." 자동 반복 대신 보통
"asdasdasd..."처럼 입력됩니다. SOCD에 지정한 키는 반복 대상에서 제외됩니다.

■ DEBOUNCE

CONFIGURE -> FEATURE -> DEBOUNCE에서 스위치 채터링 필터를 조정합니다.
기본값은 Balanced, 5 ms입니다. 한 번 눌렀는데 여러 번 입력되는 증상이 있다면
관련 시간을 조금씩 늘리십시오. 채터링 문제가 없다면 기본 설정을 유지하는 것을
권장합니다.

■ TAPPING

CONFIGURE -> FEATURE -> TAPPING에서 Mod-Tap/Layer-Tap의 탭·홀드 판정을
조정합니다. Tapping Term의 기본값은 200 ms입니다. 짧을수록 홀드가 빨리
걸리지만 빠른 타이핑이 의도치 않은 홀드로 판정될 수 있고, 길수록 안정적이지만
홀드가 늦게 들어옵니다.

- Permissive Hold: 다른 키를 눌렀다 뗄 때까지 탭·홀드 키를 계속 누르고 있으면
  홀드로 판정합니다.
- Hold On Other Key Press: 다른 키를 누르는 순간 바로 홀드로 판정합니다.
  더 빠르지만 굴려 치는 타건에서는 의도한 탭이 홀드가 될 수 있습니다.
- Retro Tapping: Term을 넘겨 눌렀더라도 그 사이 다른 키를 누르지 않았다면
  키를 뗄 때 탭을 입력합니다.

■ MOUSE

CONFIGURE -> FEATURE -> MOUSE에서 Mouse Key 동작을 조정합니다. 키맵에
Mouse Key가 없으면 입력에 영향을 주지 않습니다. 값들이 서로 영향을 주므로
한 번에 하나씩 조정하는 것을 권장합니다.

- Cursor Acceleration: 시작 속도에서 최고 속도까지 가속하는 시간. Off면 고정 속도.
- Cursor Start Speed / Top Speed: 가속 시작/종료 시 한 스텝 이동 거리.
- Cursor Speed: Acceleration이 Off일 때 한 스텝 이동 거리.
- Cursor Steps Per Second: 초당 커서 이동 스텝 수.
- Wheel Rate: 초당 스크롤 스텝 수.
- Wheel Acceleration: 누르고 있는 동안 스크롤 가속 정도.

■ ROLLOVER / NKRO

CONFIGURE -> FEATURE -> NKRO에서 NKRO를 켜고 끕니다. NKRO를 끄면 6KRO로
동작합니다. 오래된 BIOS/KVM 등에서 호환 문제가 있을 때만 끄는 것을
권장합니다.

■ LIGHTING

CONFIGURE -> LIGHTING의 RGB Matrix에서 밝기, 효과, 속도와 색을 조정합니다.
Badge Lighting은 배지 LED의 역할을 정합니다.

- RGB-Only: 선택한 RGB 효과를 배지 영역에만 적용합니다.
- Lock Indicator: Off / Caps Lock / Scroll Lock / Num Lock 중 표시할 상태를 정합니다.
- Indicator-Only: 배지 영역을 인디케이터로만 사용하며 RGB 효과는 적용하지 않습니다.
- Indicator Brightness / Indicator Color: Lock 표시의 밝기와 색을 정합니다.

■ SYSTEM

CONFIGURE -> SYSTEM에는 스플릿 전용 SYNC, LINK, SLEEP과 BOOT가 있습니다.

SYNC:
세 항목은 모두 기본 On이며 양쪽 유닛이 공유하는 영역을 각각 담당합니다.
- EEPROM SYNC: 저장 설정이 바뀌고 몇 초 뒤 인디케이터와 함께 양쪽 유닛이 값을
  맞춥니다. INPUT SYNC와 RGB SYNC가 완전히 동작하려면 먼저 켜져 있어야 합니다.
- INPUT SYNC: 양쪽 유닛을 모두 PC에 연결한 DUAL-HOST에서도 레이어 상태와 키
  입력 판정을 공유해 하나의 키보드처럼 동작하게 합니다.
- RGB SYNC: 반응형 효과를 포함해 양쪽 유닛의 조명을 맞춥니다.

LINK:
- High: 460800 bps / 1 ms (기본값)
- Medium: 230400 bps / 2 ms
- Low: 115200 bps / 4 ms

LINK 값을 고른 뒤 Apply를 사용합니다. 실제 속도가 바뀌면 양쪽 유닛이 합의해
재시작합니다. 이미 그 속도로 동작 중이면 Apply를 사용해도 재시작하지 않습니다.
빨간색 LED가 길게 세 번 깜빡이면 스플릿 케이블 품질에 문제가 있다는 뜻이므로
케이블 교체를 권장합니다. 기본값은 High입니다.

SLEEP:
RGB Sleep은 기본 On입니다. 끄면 유휴 시간뿐 아니라 USB 절전과 호스트 소실을
포함한 자동 RGB 절전 전체가 비활성화됩니다. On일 때만 시간 설정이 보이며,
마지막 입력 뒤 1/3/5/10/30/60분 중 선택합니다. 기본값은 10분입니다. 토글을
꺼도 시간 값은 보존됩니다.

BOOT:
Jump To BOOT는 켜는 즉시 현재 유닛의 부트로더로 진입합니다. 실행 후 항상
꺼진 값으로 보이는 것이 정상입니다.

■ EEPROM CLEAN

CONFIGURE -> SYSTEM -> EEPROM에서 세 확인 토글을 10초 안에 모두 켜면 CLEAN이
실행됩니다. 연결된 양쪽 유닛은 함께 초기화와 재시작을 수행하며, 떨어져 있는
유닛은 각각 로컬 CLEAN을 수행합니다. 실행 전 VIA SAVE + LOAD로 키맵을 백업하십시오.


----------------------------------------------------------------------
English
----------------------------------------------------------------------

■ Starting Official VIA

1. Open https://usevia.app.
2. Enable Show Design tab in SETTINGS.
3. In DESIGN -> Load Draft Definition, load the JSON for the unit connected by
   USB. The L file is for the left unit and the R file for the right unit.
4. For DUAL-HOST, where both units have their own USB connection, load both L
   and R definitions.
5. Use CONFIGURE for KEYMAP, LIGHTING, FEATURE, TAPDANCE, and SYSTEM.

See via_keycodes.txt in the same folder when entering keycodes directly into
TAPDANCE fields. Use VIA SAVE + LOAD to back up a keymap you want to keep.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION shows the firmware version of the unit currently
connected by USB in YYMMDDRn form. The year, month, day, and revision are read
from the unit and cannot be changed in VIA. Both units must run the same version.

■ TAPDANCE

Configure TD0 through TD7 in CONFIGURE -> TAPDANCE, then place the matching
TD number on the desired key in KEYMAP. The configured actions do nothing until
that TD key is actually placed somewhere you can press it.

- On Tap: keycode for a short tap
- On Hold: keycode for a held press
- On Double Tap: keycode for two taps inside Term
- Tap+Hold: keycode for a tap followed by a hold
- Term: how long the keyboard waits before deciding the action, in milliseconds

■ SOCD

Assign each opposing key pair in CONFIGURE -> FEATURE -> SOCD. While both are
held, the key pressed later takes priority. Releasing it restores the other key
if that key is still physically held. This is mainly useful when directional
conflicts must be unambiguous.

■ KKUK

Use CONFIGURE -> FEATURE -> KKUK. While two or more ordinary keys remain held,
KKUK periodically releases the held group and presses it again according to
Delay/Repeat. For example, holding A, S, and D usually produces "asdasdasd..."
instead of the ordinary "asdddd..." auto-repeat. Keys assigned to SOCD are
excluded.

■ DEBOUNCE

Adjust switch-chatter filtering in CONFIGURE -> FEATURE -> DEBOUNCE. The
default is Balanced, 5 ms. If one physical press sometimes produces multiple
inputs, increase the relevant delay a little at a time. If there is no chatter,
keeping the default settings is recommended.

■ TAPPING

Adjust Mod-Tap/Layer-Tap tap-hold decisions in CONFIGURE -> FEATURE -> TAPPING.
The default Tapping Term is 200 ms. Shorter makes holds trigger sooner but can
turn fast typing into accidental holds; longer is safer but makes the hold
arrive later.

- Permissive Hold: while the tap-hold key is still held, pressing and releasing
  another key makes it a hold.
- Hold On Other Key Press: another key press makes it a hold immediately. This
  is earlier, but rolling key presses can turn intended taps into holds.
- Retro Tapping: if the key is held past Term and released without another key
  press, the release still sends the tap.

■ MOUSE

Configure Mouse Keys in CONFIGURE -> FEATURE -> MOUSE. These settings do not
affect typing unless Mouse Key keycodes are present in the keymap. The values
affect one another, so adjusting one at a time is recommended.

- Cursor Acceleration: time from start speed to top speed; Off uses fixed speed.
- Cursor Start Speed / Top Speed: distance per step at start/end of acceleration.
- Cursor Speed: distance per step while Acceleration is Off.
- Cursor Steps Per Second: cursor movement steps per second.
- Wheel Rate: scroll steps per second.
- Wheel Acceleration: how strongly scrolling accelerates while held.

■ ROLLOVER / NKRO

Turn NKRO on or off in CONFIGURE -> FEATURE -> NKRO. With NKRO off the keyboard
uses 6KRO. Turning it off is mainly useful for an old BIOS, KVM, or other host
that does not accept NKRO.

■ LIGHTING

Use CONFIGURE -> LIGHTING -> RGB Matrix for brightness, effect, speed, and
colour. Badge Lighting controls the badge LED role.

- RGB-Only: apply the selected RGB effect only to the badge area.
- Lock Indicator: choose Off, Caps Lock, Scroll Lock, or Num Lock.
- Indicator-Only: use the badge area only as an indicator; RGB effects do not affect it.
- Indicator Brightness / Indicator Color: brightness and colour of the Lock indication.

■ SYSTEM

CONFIGURE -> SYSTEM includes split-specific SYNC, LINK, and SLEEP plus BOOT.

SYNC:
All three are on by default and cover different parts of what the units share.
- EEPROM SYNC: a few seconds after a stored setting changes, an indicator shows
  and the two units copy it across. INPUT SYNC and RGB SYNC need this on to work
  fully.
- INPUT SYNC: with both units plugged into the PC in DUAL-HOST, they share layer
  state and key decisions so they act as one keyboard.
- RGB SYNC: aligns lighting across both units, reactive effects included.

LINK:
- High: 460800 bps / 1 ms (default)
- Medium: 230400 bps / 2 ms
- Low: 115200 bps / 4 ms

Choose a LINK value and use Apply. If the active speed changes, both units
agree on the change and restart. Apply does nothing if that speed is already
running. Three long red LED pulses mean the split cable is not good enough;
replacing the cable is recommended. The default is High.

SLEEP:
RGB Sleep is on by default. Turning it off disables automatic RGB sleep as a
whole: idle timeout, USB suspend, and host loss. The timeout control is shown
only while RGB Sleep is on. Choose 1/3/5/10/30/60 minutes of inactivity; the
default is 10 minutes. Turning RGB Sleep off keeps that timeout for the next
time you turn it on.

BOOT:
Jump To BOOT enters the current unit's bootloader as soon as it is switched on
and normally reads back off after the action.

■ EEPROM CLEAN

Turn on all three confirmation toggles in CONFIGURE -> SYSTEM -> EEPROM within
10 seconds to run CLEAN. Connected units erase and restart together; separated
units perform local CLEAN independently. Back up the keymap with VIA SAVE + LOAD
before running CLEAN.
