# ERA Active Index

Genre: entry
Canonical for: task-based routing from ERA work to the smallest required set of
contracts, source-location aids, and validation guidance

## Use This Router

Choose the closest task row below.

- **Change** — requirements or constraints that define the behavior being
  edited. Read these before editing.
- **Locate** — source ownership, identifiers, or a cross-domain starting point. Open only
  when the task needs that lookup.
- **Verify** — acceptance or evidence guidance. Open only when the work actually
  performs that validation or makes that judgment.
- There is no always-on contract or map. In particular,
  `contracts/era_overview.md` and `contracts/era_invariants.md` are routed by
  the tasks that need them rather than by first-session status.
