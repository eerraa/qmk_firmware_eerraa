Firmware Guide
======================================================================

■ 固件更新

请使用与当前键盘匹配的固件 ZIP 文件。更新与备份说明及各功能帮助（Help）可在 https://usekb.cc 查看。

1. 将键盘切换至 Bootloader 模式。
   - 设置界面：SYSTEM -> BOOT -> Jump To BOOT
   - 按键布局中的 QK_BOOT 键
   - 按住最左上角物理按键连接 USB（Bootmagic）
   - 快速连按两次电路板上的 Reset 按钮（或快速短接两次 RST-GND）
2. 将常规固件 .uf2 复制到 RPI-RP2 磁盘（完成后自动重启）。
3. 更新后在 SYSTEM -> VERSION 中确认版本。

分体键盘请在左右两侧单元安装相同的 .uf2 文件。如果传输中断或未能正常工作，请重新进入 Bootloader 并再次复制同一文件。常规更新会保留相同存储格式下的有效设置，但存储格式变更或无效的存储数据可能会导致重置，请提前备份。旧版固件通过 Bootmagic 进入时可能会重置设置，首次更新请使用 VIA BOOT 或连按两次 Reset。

■ Reset.uf2 注意事项（重置设置）

仅在需要重置设置时安装同一 ZIP 中的 Reset.uf2。它只会在安装后的首次启动时重置所有按键布局、宏与用户设置，之后无需重新刷入常规固件即可直接使用。后续重启会保留新设置，再次安装相同的 Reset.uf2 则会再次重置一次。传输中断不代表安装完成。若重置过程中断电会自动重试；若无法开始正常使用，请通过硬件方式进入 Bootloader 重新安装同一文件。不保证安全擦除或修复物理闪存故障。

重置分体键盘时，请先断开左右两侧连接，待各单元分别完成相同的 Reset.uf2 安装与重置后再重新连接。
