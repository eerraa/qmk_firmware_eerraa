Split Firmware Guide
======================================================================

■ 固件更新

请使用与当前键盘匹配的固件 ZIP，并务必在分体键盘的左侧和右侧单元安装相同的 .uf2 文件。不支持混用不同版本的固件。

请逐侧按以下步骤操作。

1. 将单元切换至 Bootloader 模式。
   - 键盘设置界面：SYSTEM -> BOOT -> Jump To BOOT
   - 配置在按键布局中的 QK_BOOT 键
   - 按住要刷写单元最左上角的物理按键连接 USB（Bootmagic）
   - 快速连按两次该单元的 Reset 按钮，或快速短接两次 RST 与 GND（两次短接之间需完全断开）
2. 电脑出现 RPI-RP2 磁盘后，复制常规固件 .uf2（完成后自动重启）。
3. 在另一侧单元也安装相同的 .uf2 文件，并在各单元的 SYSTEM -> VERSION 中确认版本。

旧版固件通过 Bootmagic 进入时可能会重置设置，因此各单元首次更新请使用 VIA BOOT 或连按两次 Reset。常规更新会保留相同存储格式下的有效按键布局、宏与设置，但存储格式变更或无效的存储数据无论以何种方式进入都可能重置为默认值。在更新或执行 EEPROM CLEAN 前，请使用 VIA SAVE + LOAD 备份按键布局。切勿在常规更新中使用 Reset.uf2。

■ 设置恢复与重置

同一 ZIP 中的 Reset.uf2 包含常规固件的全部功能。它仅在安装后的首次启动时重置当前所有设置（按键布局、宏、用户设置），无需再刷入常规固件即可直接作为键盘使用。如条件允许，请先备份。

请断开分体连接线并分别重置各个单元。如果只重置一侧，未重置的另一侧可能会将旧设置恢复回来。

1. 让各单元进入 Bootloader 并复制相同的 Reset.uf2。
2. 等待各单元完成重置并重新作为键盘连接。
3. 两侧均完成后，重新连接分体连接线并重新配置使用。

后续重启会保留新保存的设置；若再次安装相同的 Reset.uf2，则会再次重置一次。传输中断不代表安装完成，必须重新上传。若重置过程中断电会自动重试；若无法开始正常使用，请使用该单元的硬件 Bootloader 进入方式重新上传相同的 Reset.uf2。它不会擦除整个芯片或引导加载程序，也不保证安全擦除或修复物理闪存故障。

■ 键盘设置

键盘设置与高级功能推荐使用 https://usekb.cc 及各设置菜单旁的 Help。Tap Dance 的高级输入模式与长按设置在 usekb.cc 中提供支持，官方 VIA 仅编辑基础动作和 Term。

若要直接使用官方 VIA（https://usevia.app），请查看发布 ZIP 中 usevia.app/usevia.txt 关于加载左/右 Draft Definition、分体专属设置以及连接·同步 STATUS 指示的说明。
