======================================================================
Split Official VIA Guide
======================================================================

本文档为直接使用官方 VIA（https://usevia.app）时的说明。日常设置、高级编辑以及自动刷新的状态显示，推荐使用 https://usekb.cc 及各菜单旁的 Help。

■ 开始使用官方 VIA

请使用与当前键盘匹配的发布 ZIP 内的 JSON 文件。

1. 访问 https://usevia.app 。
2. 在 SETTINGS 中开启 Show Design tab。
3. 在 DESIGN -> Load Draft Definition 中加载当前要连接 USB 的单元对应的 VIA JSON。L 文件用于左侧单元，R 文件用于右侧单元。
4. 若以 DUAL-HOST 方式将左右两侧单元分别连接 USB，请同时加载 L/R 两个 JSON。
5. 在 CONFIGURE 中配置 KEYMAP、LIGHTING、FEATURE、TAPDANCE、SYSTEM。

在 TAPDANCE 输入框中直接填写 keycode 时，请参考同一文件夹下的 via_keycodes.txt。如需保存按键布局，请在 VIA 的 SAVE + LOAD 中备份。

常规更新会保留相同存储格式下的有效设置，但存储格式变更或无效的存储数据可能会导致重置。Reset.uf2 并非用于常规更新，而是仅在安装后首次启动时清除所有当前设置的全功能固件。重置后可直接使用，新设置在重启后也会保留；再次安装同一文件则会再次重置。必须断开连接线并分别重置左右两侧单元。备份与恢复步骤请遵循发布 ZIP 中的 readme.txt。

■ VERSION

CONFIGURE -> SYSTEM -> VERSION 以 YYMMDDRn 格式显示当前通过 USB 连接的单元固件版本，无法在 VIA 中修改。左右两侧单元必须使用相同版本。

■ MATRIX TEST

VIA 的 Matrix Test 显示当前 USB 单元所构成的物理矩阵按下状态。可使用 VIA Raw HID 的主机程序能够查询当前按下的矩阵位置，请在受信任的电脑上使用。

■ TAPDANCE

在 CONFIGURE -> TAPDANCE 中设置 TD0~TD7 后，在 KEYMAP 中将相同的 TD 编号放置到所需位置。在将 TD 键实际放置到按键布局之前，所设定的动作不会执行。

- On Tap：短按轻点时的 keycode
- On Hold：长按时的 keycode
- On Double Tap：在 Term 时间内双击轻点时的 keycode
- Tap+Hold：轻点一次后紧接着长按时的 keycode
- Term：判定不同输入动作的时间。在官方 VIA 中以 20ms 为单位在 100~500ms 之间选择。

在 Legacy 模式下，若将 On Double Tap 和 Tap+Hold 留空，该槽位会在松开按键的瞬间输入轻点，Term 仅用于长按判定。若设置了 On Double Tap，则在第二次轻点松开的瞬间输入。

官方 VIA 仅编辑 Legacy 模式的基础动作和 Term。对于使用高级模式或未知模式值的槽位，仅显示 usekb.cc 提示且不编辑基础动作。更改输入模式、独立长按时间以及按下其他键时触发长按等设置，请前往 https://usekb.cc 使用。仅打开官方 VIA 或加载定义不会改变槽位的模式或动作。

■ SOCD

在 CONFIGURE -> FEATURE -> SOCD 中指定两个相反方向的按键（左/右、上/下），并在 Mode 中选择同时按住这两个按键时要发送给电脑的按键。

- Last Input：仅发送后按下的按键。松开该键后，仍按住的另一个按键会立即恢复输入（快速切换）。此为默认值。
- Neutral：两个按键均不发送。
- First Input：保持发送先按下的按键。
- Left/Up Priority, Right/Down Priority：无论按下顺序如何，始终发送指定方向的按键。

请将按键指定为普通键或修饰键（modifier）。由于按发送给电脑的按键进行判定，因此同样适用于由 Tap Dance 或宏输出的按键。若在同一对的两个栏位中填入相同按键将不会生效；若已开启的两对共用了同一个有效按键，则这两对都不会生效。已关闭配对的按键设置不会影响其他配对。在 DUAL-HOST 模式下，左右两个单元各自向电脑发送按键，因此同一对的两个按键必须位于同一单元才能生效。部分游戏和赛事限制使用 SOCD，请先确认相关规则。

■ KKUK

在 CONFIGURE -> FEATURE -> KKUK 中使用。持续按住两个以上普通键时，会根据 Delay/Repeat 设置周期性地松开并重新按下所按住的按键组合。例如持续按住 A、S、D 时，将输入类似“asdasdasd...”而非普通的“asdddd...”自动重复。此功能并非字符串宏或防矩阵鬼键（ghosting）功能。仅排除已开启、有效且未与其他配对冲突的 SOCD 配对按键；已关闭配对或无效、冲突配对的按键不会被排除。

■ DEBOUNCE

在 CONFIGURE -> FEATURE -> DEBOUNCE 中调整轴体连击抖动滤波。默认值为 Balanced、5 ms。仅在出现按一次却输入多次的现象时逐步调大相关时间；若无问题请保持默认设置。

■ TAPPING

在 CONFIGURE -> FEATURE -> TAPPING 中调整 Mod-Tap/Layer-Tap 的轻点与长按判定。Tapping Term 的默认值为 200 ms。数值越小长按触发越快，但快速打字时可能被误判为长按；数值越大越稳定，但长按触发会变慢。

- Permissive Hold：在按下并松开其他按键期间一直按住轻点·长按双用键时，判定为长按。
- Hold On Other Key Press：按下其他按键的瞬间立即判定为长按。响应更快，但在滚键输入（前键未松开就按下一键的连续敲击）时，原本意图的轻点可能会变成长按。
- Retro Tapping：即使按住时间超过 Term，只要期间没有按过其他按键，松开按键时仍输入轻点。

■ MOUSE

整数精度的精细输入在 usekb.cc 的高级设置中提供。官方 VIA 显示最接近的预设档位，仅查询不会改变原有精细数值。滚轮加速在时间为 0 时显示 Off，其余情况根据目标速度显示 Mild/Strong。选择预设档位后将更改为对应设置。

在 CONFIGURE -> FEATURE -> MOUSE 中调整 Mouse Key 动作。如果按键布局中没有配置 Mouse Key，则不会影响输入。由于各项数值相互影响，请每次只调整一项。

- Cursor Acceleration：从起始速度加速到最高速度的时间。设为 Off 时为固定速度。
- Cursor Start Speed / Top Speed：加速开始/结束时单步移动的距离。
- Cursor Speed：Acceleration 设为 Off 时单步移动的距离。
- Cursor Steps Per Second：每秒光标移动步数。
- Wheel Rate：每秒滚动步数。
- Wheel Acceleration：按住期间的滚动加速程度。

■ ROLLOVER / NKRO

在 CONFIGURE -> FEATURE -> NKRO 中开启或关闭 NKRO。默认值为关闭（6KRO），开启后会报告所有同时按下的按键。如果开启后旧版 BIOS/KVM 或启动菜单无法识别键盘，请将其重新关闭。

■ LIGHTING

在 CONFIGURE -> LIGHTING 的 Per-Key RGB 中调整亮度、灯效、速度与颜色。Badge 用于决定铭牌 LED 的作用。

- RGB-Only：将所选 RGB 灯效仅应用于铭牌区域。
- Indicator：在 RGB Effect / Caps Lock / Scroll Lock / Num Lock 中选择要显示的状态。若设为 RGB Effect，铭牌将原样显示 RGB 灯效。
- Indicator-Only：将铭牌区域专用于锁定状态指示。不显示普通 RGB 灯效，但仍可能显示连接与同步的临时 STATUS 提示。
- Indicator Brightness / Indicator Color：设置 Lock 指示的亮度与颜色。

■ SYSTEM

CONFIGURE -> SYSTEM 中包含分体专属的 SYNC 与 LINK，以及 SLEEP 和 BOOT。

SYNC:
三项设置默认均为 On，且彼此独立。
- EEPROM SYNC：同步左右两侧单元已保存的设置。同步操作显示期间 STATUS 为蓝色。它并非 INPUT SYNC 和 RGB SYNC 的前置条件，但若要保持两侧按键布局和设置一致，建议保持开启。
- INPUT SYNC：在左右两个单元同时连接电脑的 DUAL-HOST 模式下共享层状态与按键输入判定，使其像同一个键盘一样工作。
- RGB SYNC：在 DUAL-HOST 模式下同步左右两侧单元的灯光（包括按键响应灯效）。
INPUT SYNC 和 RGB SYNC 控制 DUAL-HOST 模式下的共享范围。在仅一侧连接 USB 的 HOST-PEER 模式下，即使关闭这两项设置，输入与灯光的传递仍会保持。

LINK:
- High：460800 bps / 1 ms（默认值）
- Medium：230400 bps / 2 ms
- Low：115200 bps / 4 ms

当前运行与保存的速度及应用结果请在 usekb.cc Custom 应用中确认。官方 VIA 中的 LINK 选择值并不代表已成功应用。选择 LINK 数值后请使用 Apply。已连接的左右两侧单元会在达成一致的时刻一同切换速度，无需重启键盘或断开 USB 连接。

TOMAK-TKL、TOMAK79H、TOMAK79S 会在整个 RGB 区域显示临时 STATUS。
- 绿色 1 次：接收到命令的单元 Apply 成功。包括运行速度与保存速度原本已一致的情况，但不代表已确认另一侧也已完成保存。
- 红色 1 次：请求无法处理、已取消或失败。
- 两侧绿色短闪 2 次：速度探测后恢复连接。
- 红色长闪 3 次：因连接速度失败而降级至 Low 的恢复警告。若反复出现，请检查或更换连接线。仅凭此提示无法断定具体原因。
- 蓝色：正在执行 EEPROM 同步操作。
RGB 睡眠期间不会显示 STATUS。普通锁定指示灯的自定义颜色与 STATUS 颜色含义相互独立。

SLEEP:
RGB Sleep 默认为 On。关闭后将禁用包括空闲超时、USB 睡眠和主机断开在内的全部自动 RGB 睡眠。仅在设为 On 时显示时间设置，可在最后一次输入后的 1/3/5/10/30/60 分钟之间选择，默认值为 10 分钟。关闭开关后该时间值仍会保留。

BOOT:
开启 Jump To BOOT 会请求当前单元进入引导加载程序。执行后始终显示为关闭状态属正常现象。

■ EEPROM CLEAN

三个确认开关没有时间限制。关闭已开启的开关仅取消该项确认，重启则会清除所有确认状态。

在 CONFIGURE -> SYSTEM -> EEPROM 中将三个确认开关全部开启后会请求执行 CLEAN。正常通信的左右两侧单元会经达成一致后一同重置按键布局、宏与所有设置并重启；断开连接的单元则各自执行本地 CLEAN。执行前请通过 VIA SAVE + LOAD 备份按键布局。
