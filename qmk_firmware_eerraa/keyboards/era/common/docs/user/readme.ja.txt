■ ファームウェアアップデート

ご使用中のキーボードに合ったファームウェア ZIP ファイルを使用してください。アップデート・バックアップ案内および機能別ヘルプ（Help）は https://usekb.cc で確認できます。

1. キーボードを Bootloader モードに切り替えます。
   - 設定画面：SYSTEM -> BOOT -> Jump To BOOT
   - キーマップの QK_BOOT キー
   - 一番左上の物理キーを押したまま USB 接続（Bootmagic）
   - 基板の Reset ボタンを素早く二回押す（または RST-GND を二回短く接続）
2. RPI-RP2 ドライブに通常ファームウェアの .uf2 をコピーします（完了後に自動再起動）。
3. アップデート後、SYSTEM -> VERSION でバージョンを確認します。

スプリットキーボードは左右のユニットに同じ .uf2 ファイルをインストールしてください。転送が中断された場合や正常に動作しない場合は、Bootloader に再度入って同じファイルをもう一度コピーしてください。通常のアップデートでは同じ保存形式の有効な設定が維持されますが、形式変更や無効な保存データによって初期化されることがあるため、先にバックアップしてください。以前のファームウェアは Bootmagic での進入時に初期化されることがあるため、最初のアップデートには VIA BOOT または Reset 二回押しを使用してください。

■ Reset.uf2 の注意（設定初期化）

設定の初期化が必要なときだけ、同じ ZIP 内の Reset.uf2 をインストールしてください。インストール後の初回起動時のみキーマップ・マクロ・ユーザー設定をすべて初期化し、通常ファームウェアを入れ直す必要なくそのまま使用できます。以降の再起動では新しい設定が維持され、同じ Reset.uf2 を再度インストールすると再び一回初期化されます。転送の中断はインストール完了ではありません。初期化中に電源が切れた場合は再試行され、正常な使用が始まらない場合はハードウェア Bootloader から同じファイルを再度インストールしてください。完全消去（セキュア消去）や物理的なフラッシュ故障の修復は保証しません。

スプリットキーボードを初期化するときは、左右の接続を外し、それぞれに同じ Reset.uf2 のインストールと初期化をすべて終えてから再接続してください。

■ キーボード設定

キーボード設定と高度な機能には https://usekb.cc と各メニュー横の Help を使用してください。公式 VIA（https://usevia.app）の使い方は usevia.app/usevia.txt を参照してください。
