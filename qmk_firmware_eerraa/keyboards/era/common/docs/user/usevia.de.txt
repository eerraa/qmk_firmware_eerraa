======================================================================
Official VIA Guide
======================================================================

Dieses Dokument dient als Anleitung für die direkte Nutzung des offiziellen VIA (https://usevia.app). Für allgemeine Einstellungen, erweiterte Bearbeitung und automatisch aktualisierte Statusanzeigen werden https://usekb.cc sowie Help neben dem jeweiligen Menü empfohlen.

■ Erste Schritte mit dem offiziellen VIA

Verwenden Sie die zur Tastatur passende JSON-Datei aus der Release-ZIP.

1. Rufen Sie https://usevia.app auf.
2. Aktivieren Sie unter SETTINGS die Option Show Design tab.
3. Laden Sie unter DESIGN -> Load Draft Definition die VIA-JSON für diese Tastatur.
   Falls L/R-Dateien vorhanden sind, verwenden Sie die zur aktuell per USB verbundenen Hälfte passende Datei; wenn Sie beide Hälften separat per USB verbinden, laden Sie beide JSON-Dateien.
4. Erlauben Sie unter CONFIGURE mit Authorize device die Verbindung und richten Sie anschließend KEYMAP, LIGHTING, FEATURE, TAPDANCE und SYSTEM ein.

Wenn Sie einen Keycode direkt in ein TAPDANCE-Eingabefeld eintragen, beachten Sie via_keycodes.txt im selben Ordner. SAVE + LOAD im offiziellen VIA sichert nur Tastenbelegungen und Makros, nicht jedoch alle Menüeinstellungen; notieren Sie andere Einstellungen daher separat.

Ein reguläres Update behält gültige Einstellungen desselben Speicherformats bei, doch eine Änderung des Speicherformats oder ungültige Speicherdaten können ein Zurücksetzen auslösen. Reset.uf2 ist kein reguläres Update, sondern eine vollwertige Firmware, die beim ersten Start nach der Installation einmalig alle aktuellen Einstellungen löscht. Nach dem Zurücksetzen wird sie direkt weiterverwendet, und neue Einstellungen bleiben auch nach einem Neustart erhalten. Eine erneute Installation derselben Datei setzt die Einstellungen wieder zurück. Folgen Sie für Sicherung und Wiederherstellung der Datei readme.txt in der Release-ZIP.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION zeigt die Firmware-Version der Tastatur im Format YYMMDDRn an und kann in VIA nicht geändert werden. Geben Sie diesen Wert bei Fehlermeldungen bitte mit an.

■ MATRIX TEST

Matrix Test in VIA zeigt physische Matrix-Tastendrücke an. Da Host-Programme mit Zugriff auf VIA Raw HID aktuell gedrückte Matrix-Positionen abfragen können, sollten Sie die Funktion nur an einem vertrauenswürdigen PC verwenden.

■ TAPDANCE

Konfigurieren Sie TD0~TD7 unter CONFIGURE -> TAPDANCE und platzieren Sie anschließend unter KEYMAP dieselbe TD-Nummer an der gewünschten Position. Bevor die TD-Taste in der tatsächlichen Tastenbelegung platziert ist, wird die eingestellte Aktion nicht ausgeführt.

- On Tap: Keycode beim kurzen Tippen
- On Hold: Keycode beim gedrückt Halten
- On Double Tap: Keycode beim zweimaligen Tippen innerhalb von Term
- Tap+Hold: Keycode beim einmaligen Tippen und anschließendem gedrückt Halten
- Term: Zeitfenster zur Unterscheidung mehrerer Eingabeaktionen. Im offiziellen VIA wählen Sie zwischen 100~500ms in 20ms-Schritten.

Sind im Legacy-Modus On Double Tap und Tap+Hold bei einem Slot leer, wird das Tippen sofort beim Loslassen der Taste ausgelöst und Term dient nur zur Erkennung des Haltens. Ist On Double Tap belegt, erfolgt die Eingabe beim Loslassen des zweiten Tippens.

Das offizielle VIA bearbeitet nur Grundaktionen und Term im Legacy-Modus. Bei Slots mit erweitertem Modus oder unbekanntem Moduswert zeigt es lediglich einen Hinweis auf usekb.cc an und bearbeitet auch die Grundaktionen nicht. Nutzen Sie https://usekb.cc für das Ändern des Eingabemodus, eine unabhängige Haltezeit sowie die Einstellung für Halten beim Drücken einer anderen Taste. Allein das Öffnen des offiziellen VIA oder das Laden einer Definition ändert weder den Modus noch die Aktionen eines Slots.

■ SOCD

Weisen Sie unter CONFIGURE -> FEATURE -> SOCD zwei entgegengesetzte Tasten (links/rechts, oben/unten) zu und wählen Sie unter Mode aus, welche Taste an den PC gesendet wird, während beide Tasten gemeinsam gedrückt gehalten werden.

- Last Input: Sendet nur die später gedrückte Taste. Wird diese Taste losgelassen, wird die andere noch gedrückt gehaltene Taste sofort wieder eingegeben (Snap Tap). Dies ist der Standardwert.
- Neutral: Sendet keine der beiden Tasten.
- First Input: Behält die zuerst gedrückte Taste bei.
- Left/Up Priority, Right/Down Priority: Sendet unabhängig von der Reihenfolge des Drückens die festgelegte Seite.

Weisen Sie den Tasten reguläre Tasten oder Modifier-Tasten zu. Da die Auswertung anhand der an den PC gesendeten Tasten erfolgt, gilt sie auch für Tasten, die von Tap Dance oder Makros ausgelöst werden. Wird in beide Felder eines Paares dieselbe Taste eingetragen, funktioniert es nicht; teilen sich zwei aktivierte Paare dieselbe gültige Taste, funktionieren beide Paare nicht. Die Tastenzuweisung eines deaktivierten Paares blockiert andere Paare nicht. Da einige Spiele und Turniere die Nutzung von SOCD einschränken, prüfen Sie bitte das jeweilige Regelwerk.

■ KKUK

Wird unter CONFIGURE -> FEATURE -> KKUK verwendet. Werden zwei oder mehr reguläre Tasten gedrückt gehalten, wird die gedrückte Tastengruppe entsprechend den Einstellungen für Delay/Repeat periodisch losgelassen und erneut gedrückt. Werden beispielsweise A, S und D gedrückt gehalten, wird statt der üblichen automatischen Wiederholung „asdddd...“ die Folge „asdasdasd...“ eingegeben. Dies ist weder ein Textmakro noch eine Funktion gegen Matrix-Ghosting. Nur Tasten eines aktivierten, gültigen und sich nicht mit einem anderen Paar überschneidenden SOCD-Paares sind von der Wiederholung ausgenommen; Tasten deaktivierter, ungültiger oder in Konflikt stehender Paare werden nicht ausgenommen.

■ DEBOUNCE

Passen Sie unter CONFIGURE -> FEATURE -> DEBOUNCE den Filter gegen Schalterprellen an. Der Standardwert ist Balanced, 5 ms. Erhöhen Sie die entsprechende Zeit nur dann schrittweise, wenn ein einzelner Tastendruck mehrfach ausgelöst wird, und behalten Sie die Standardeinstellung bei, wenn keine Probleme auftreten.

■ TAPPING

Passen Sie unter CONFIGURE -> FEATURE -> TAPPING die Tipp-/Halte-Erkennung für Mod-Tap/Layer-Tap an. Der Standardwert für Tapping Term beträgt 200 ms. Kürzere Werte lösen das Halten schneller aus, können aber schnelles Tippen unbeabsichtigt als Halten werten; längere Werte sind stabiler, verzögern jedoch das Auslösen des Haltens.

- Permissive Hold: Wertet die Eingabe als Halten, wenn die Tipp-/Halte-Taste weiter gedrückt gehalten wird, bis eine andere Taste gedrückt und wieder losgelassen wurde.
- Hold On Other Key Press: Wertet die Eingabe sofort in dem Moment als Halten, in dem eine andere Taste gedrückt wird. Reagiert schneller, kann jedoch beim rollenden Tippen ein beabsichtigtes Tippen zum Halten machen.
- Retro Tapping: Gibt beim Loslassen der Taste ein Tippen ein, selbst wenn Term überschritten wurde, sofern in der Zwischenzeit keine andere Taste gedrückt wurde.

■ MOUSE

Eine präzise ganzzahlige Eingabe steht in den erweiterten Einstellungen auf usekb.cc zur Verfügung. Das offizielle VIA zeigt die nächstgelegene Voreinstellung an und verändert präzise Werte nicht allein durch das Anzeigen. Bei der Mausradbeschleunigung wird bei einer Zeit von 0 Off angezeigt, andernfalls anhand der Zielgeschwindigkeit Mild/Strong. Durch Auswählen einer Voreinstellung wird diese Einstellung übernommen.

Passen Sie unter CONFIGURE -> FEATURE -> MOUSE das Verhalten von Mouse Key an. Befindet sich keine Mouse Key in der Tastenbelegung, hat dies keinen Einfluss auf die Eingabe. Da sich die Werte gegenseitig beeinflussen, sollten Sie sie einzeln nacheinander anpassen.

- Cursor Acceleration: Zeit für die Beschleunigung von der Startgeschwindigkeit bis zur Höchstgeschwindigkeit. Bei Off feste Geschwindigkeit.
- Cursor Start Speed / Top Speed: Bewegungsdistanz pro Schritt zu Beginn/Ende der Beschleunigung.
- Cursor Speed: Bewegungsdistanz pro Schritt, wenn Acceleration auf Off steht.
- Cursor Steps Per Second: Anzahl der Cursor-Bewegungsschritte pro Sekunde.
- Wheel Rate: Anzahl der Scrollschritte pro Sekunde.
- Wheel Acceleration: Stärke der Scrollbeschleunigung während des Gedrückthaltens.

■ ROLLOVER / NKRO

Schalten Sie NKRO unter CONFIGURE -> FEATURE -> NKRO ein oder aus. Standardmäßig ist es ausgeschaltet (6KRO); im eingeschalteten Zustand werden alle gedrückten Tasten gemeldet. Falls ein älteres BIOS/KVM oder Boot-Menü die Tastatur nach dem Einschalten nicht erkennt, schalten Sie es wieder aus.

■ LIGHTING

Legen Sie unter CONFIGURE -> LIGHTING Helligkeit, Effekt und Farbe der auf dem Bildschirm angezeigten Beleuchtungselemente fest. Passen Sie Geschwindigkeit oder Periode eines Effekts über die für den jeweiligen Effekt bereitgestellten Optionen an.

Auf Platinen, die Backlight Pulse unterstützen, lauten die Effektnamen wie folgt.

- Steady
- Breathing
- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Wenn Breathing ausgewählt ist, regelt Breathing Period (1~10) den Atmungszyklus, wobei kleinere Werte schneller sind. Pulse Speed wird nur bei Pulse angezeigt, und die Pulsdauer beträgt 5 + Wert ms (0 entspricht 5 ms, 255 entspricht 260 ms, der Standardwert 15 entspricht 20 ms). Hold-Effekte bleiben auch nach Ablauf der Pulsdauer aktiv, solange eine unter diesem Effekt neu gedrückte physische Taste weiterhin gehalten wird; bereits vor der Effektauswahl gedrückt gehaltene Tasten werden nicht gehalten. Das erneute Auswählen eines Effekts, das Ausschalten der Beleuchtung oder der Wechsel in den Ruhezustand beendet einen laufenden Pulse, und während des Ruhezustands gedrückte Tasten erzeugen keinen Pulse.

RGBLight-Beleuchtungen (Underglow, Badge, RGB LEDs) bieten in der Liste Effect nach Twinkle 6 dieselben vier Pulse-Effekte. Effect Speed wird nur bei diesen vier Effekten angezeigt und regelt die Pulsdauer auf dieselbe Weise. Die Geschwindigkeit regulärer Effekte wie Breathing 1~4 wird über die Nummer unter Effect gewählt, und bei unterstützten Effekten kann über Velocikey auf die Tippgeschwindigkeit reagiert werden.

- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Indicators dient zur Statusanzeige von Caps/Scroll/Num Lock. Wählen Sie den anzuzeigenden Status unter Indicator (bei mehreren unter Indicator 1, 2 …). Der Wert 0 entspricht bei Platinen, die Anzeige-LEDs gemeinsam mit RGB-Effekten nutzen, RGB Effect (der Effekt bleibt unverändert sichtbar) und bei Platinen mit dedizierten LEDs Off. Wählen Sie das Anzeigeziel sowie die auf dem Bildschirm angebotenen Helligkeits- und Farboptionen.

- RGB Effect
- Caps Lock
- Scroll Lock
- Num Lock

LEDs mit der Einstellung RGB Effect nehmen weiterhin an regulären RGB-Effekten teil. LEDs mit einem Lock-Status verwenden bei aktiviertem Lock die Werte Brightness und Color des jeweiligen Indicator. Ist Indicator-Only aktiviert, bleiben Anzeige-LEDs mit ausgeschaltetem Lock dunkel, während LEDs mit RGB Effect weiterhin RGB-Effekte anzeigen. Brightness/Color werden für Indicator 1/2/3 jeweils unabhängig eingestellt.

■ SYSTEM

Wenn SYNC und LINK auf dem Bildschirm verfügbar sind, verwenden Sie diese wie folgt. EEPROM SYNC synchronisiert gespeicherte Einstellungen. INPUT SYNC und RGB SYNC teilen Eingabeauswertung und Beleuchtung unter DUAL-HOST, wenn beide Hälften jeweils separat per USB verbunden sind. Alle drei Einstellungen sind unabhängig voneinander und standardmäßig auf On gesetzt. Unter HOST-PEER mit nur einer per USB verbundenen Hälfte bleibt die Weiterleitung von Eingaben und Beleuchtung auch dann erhalten, wenn INPUT SYNC und RGB SYNC ausgeschaltet sind.

Wählen Sie unter LINK zwischen High (460800 bps / 1 ms, Standardwert), Medium (230400 bps / 2 ms) und Low (115200 bps / 4 ms) und klicken Sie anschließend auf Apply. Die verbundenen Hälften schalten zu einem abgestimmten Zeitpunkt gemeinsam um, ohne Neustart oder Trennen der USB-Verbindung. Da der Auswahlwert im offiziellen VIA nicht bedeutet, dass die Übernahme abgeschlossen ist, prüfen Sie die aktive/gespeicherte Geschwindigkeit und das Ergebnis unter usekb.cc Custom.

Stellen Sie unter SYSTEM -> SLEEP den automatischen Ruhezustand für RGB und Hintergrundbeleuchtung getrennt ein. Es werden nur Einträge für Beleuchtungen angezeigt, die an der Tastatur vorhanden sind.

- RGB Sleep, Backlight Sleep: Standardmäßig auf On. Bei Einstellung auf Off schaltet sich die jeweilige Beleuchtung weder nach Leerlaufzeit noch bei USB-Ruhezustand oder Verbindungsverlust zum Host aus.
- RGB Sleep Timeout, Backlight Sleep Timeout: Nur sichtbar, wenn der jeweilige Ruhezustand auf On steht; wählen Sie 1/3/5/10/30/60 Minuten nach der letzten Eingabe. Der Standardwert beträgt 10 Minuten, und der Wert bleibt auch beim Ausschalten des Schalters erhalten.

Der Ruhezustand schaltet lediglich die Beleuchtungsausgabe aus, ohne die Einstellungen zu verändern. Durch eine Eingabe oder eine normale Rückkehr des Hosts schaltet sie sich wieder ein; vom Benutzer ausgeschaltete Beleuchtung wird jedoch nicht automatisch eingeschaltet. Bei Tastaturen, deren Hintergrundbeleuchtung zugleich als Lock-Anzeige dient, schaltet sich im Ruhezustand der Hintergrundbeleuchtung auch die Anzeige aus.

Das Einschalten von Jump To BOOT unter SYSTEM -> BOOT fordert den Wechsel in den Bootloader an. Es ist normal, dass der Schalter nach der Ausführung immer als ausgeschaltet angezeigt wird.

■ EEPROM CLEAN

Für die drei Bestätigungsschalter gibt es kein Zeitlimit. Wird ein eingeschalteter Schalter wieder ausgeschaltet, wird nur diese Bestätigung zurückgenommen; ein Neustart löscht alle Bestätigungszustände.

Wenn Sie unter CONFIGURE -> SYSTEM -> EEPROM alle drei Bestätigungsschalter einschalten, werden gespeicherte Tastenbelegungen, Makros und sämtliche Einstellungen zurückgesetzt und die Tastatur startet neu. Sichern Sie vor der Ausführung Ihre Daten über VIA SAVE + LOAD und notieren Sie andere Einstellungen. Bei Split-Tastaturen mit normaler Kommunikation stimmen sich beide Hälften ab und setzen sich gemeinsam zurück; getrennte Hälften führen jeweils lokal ein CLEAN durch.
