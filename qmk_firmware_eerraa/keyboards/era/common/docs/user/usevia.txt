----------------------------------------------------------------------
한국어
----------------------------------------------------------------------

이 문서는 공식 VIA(https://usevia.app)를 직접 사용할 때의 안내입니다. 일반 설정과 고급 편집, 자동 갱신 상태 표시는 https://usekb.cc 와 각 메뉴 옆 Help를 권장합니다.

■ 공식 VIA 시작

사용 중인 키보드에 맞는 배포 ZIP 안의 JSON을 사용하십시오.

1. https://usevia.app 에 접속합니다.
2. SETTINGS에서 Show Design tab을 켭니다.
3. DESIGN -> Load Draft Definition에서 이 키보드의 VIA JSON을 불러옵니다.
   L/R 파일이 있으면 현재 USB 유닛에 맞는 것을 사용하고, 양쪽을 각각 USB로 연결할 때는 두 JSON을 모두 불러옵니다.
4. CONFIGURE의 Authorize device로 연결을 허용한 뒤 KEYMAP, LIGHTING, FEATURE, TAPDANCE, SYSTEM을 설정합니다.

TAPDANCE 입력창에 직접 keycode를 넣을 때는 같은 폴더의 via_keycodes.txt를 참고하십시오. 공식 VIA SAVE + LOAD는 키맵과 매크로만 백업하며 모든 메뉴 설정을 백업하지 않으므로, 다른 설정은 별도로 기록하십시오.

일반 업데이트는 같은 저장 형식의 유효한 설정을 유지하지만 저장 형식 변경이나 잘못된 저장 데이터는 초기화를 일으킬 수 있습니다. Reset.uf2는 일반 업데이트가 아닌 설치 후 최초 한 번 모든 현재 설정을 지우는 전체 기능 펌웨어입니다. 초기화 후 그대로 사용하며 새 설정은 재부팅에도 유지됩니다. 같은 파일을 다시 설치하면 다시 초기화됩니다. 백업과 복구 절차는 배포 ZIP의 readme.txt를 따르십시오.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION은 키보드의 펌웨어 버전을 YYMMDDRn 형식으로 표시하며 VIA에서 수정할 수 없습니다. 문제를 제보할 때 이 값을 함께 적어 두십시오.

■ MATRIX TEST

VIA의 Matrix Test는 물리 매트릭스 눌림을 표시합니다. VIA Raw HID를 사용할 수 있는 호스트 프로그램은 현재 눌린 매트릭스 위치를 조회할 수 있으므로 신뢰할 수 있는 PC에서 사용하십시오.

■ TAPDANCE

CONFIGURE -> TAPDANCE에서 TD0~TD7을 설정한 뒤 KEYMAP에서 같은 TD 번호를 원하는 위치에 배치합니다. TD 키를 실제 키맵에 배치하기 전에는 설정한 동작이 실행되지 않습니다.

- On Tap: 짧게 탭했을 때의 keycode
- On Hold: 길게 눌렀을 때의 keycode
- On Double Tap: Term 안에 두 번 탭했을 때의 keycode
- Tap+Hold: 한 번 탭한 뒤 이어서 길게 눌렀을 때의 keycode
- Term: 여러 입력 동작을 판정하는 시간. 공식 VIA에서는 100~500ms를 20ms 단위로 선택합니다.

Legacy에서 On Double Tap과 Tap+Hold를 비워 둔 슬롯은 키를 떼는 순간 탭이 입력되고, Term은 홀드 판정에만 쓰입니다. On Double Tap을 설정하면 두 번째 탭을 떼는 순간 입력됩니다.

공식 VIA는 Legacy 모드의 기본 동작과 Term만 편집합니다. 고급 모드나 알 수 없는 모드값의 슬롯에는 usekb.cc 안내만 표시하며 기본 동작도 편집하지 않습니다. 입력 모드 변경, 독립 홀드 시간, 다른 키 누름 시 홀드 설정은 https://usekb.cc 에서 사용하십시오. 공식 VIA를 열거나 정의를 불러오는 것만으로 슬롯의 모드나 동작을 바꾸지는 않습니다.

■ SOCD

CONFIGURE -> FEATURE -> SOCD에서 서로 반대되는 두 키(좌/우, 상/하)를 지정하고, 두 키를 함께 누르고 있을 때 PC로 보낼 키를 Mode에서 고릅니다.

- Last Input: 나중에 누른 키만 보냅니다. 그 키를 떼면 아직 누르고 있는 다른 키가 곧바로 다시 입력됩니다(스냅 탭). 기본값입니다.
- Neutral: 두 키 모두 보내지 않습니다.
- First Input: 먼저 누른 키를 유지합니다.
- Left/Up Priority, Right/Down Priority: 누른 순서와 상관없이 지정한 쪽을 보냅니다.

키에는 일반 키나 modifier 키를 지정하십시오. PC로 나가는 키를 기준으로 판정하므로 Tap Dance나 매크로가 낸 키에도 적용됩니다. 한 쌍의 두 칸에 같은 키를 넣으면 동작하지 않고, 켜진 두 쌍이 유효한 같은 키를 공유하면 두 쌍 모두 동작하지 않습니다. 꺼진 쌍의 키 지정은 다른 쌍을 막지 않습니다. 일부 게임과 대회는 SOCD 사용을 제한하므로 규정을 확인하십시오.

■ KKUK

CONFIGURE -> FEATURE -> KKUK에서 사용합니다. 일반 키 두 개 이상을 계속 누르면 눌린 키 묶음을 Delay/Repeat 설정에 따라 주기적으로 뗐다가 다시 누릅니다. 예를 들어 A, S, D를 계속 누르면 일반적인 "asdddd..." 자동 반복 대신 "asdasdasd..."처럼 입력됩니다. 문자열 매크로나 매트릭스 ghosting 방지 기능이 아닙니다. 켜져 있고 유효하며 다른 쌍과 겹치지 않는 SOCD 쌍의 키만 반복 대상에서 제외되며, 꺼진 쌍이나 무효·충돌한 쌍의 키는 제외하지 않습니다.

■ DEBOUNCE

CONFIGURE -> FEATURE -> DEBOUNCE에서 스위치 채터링 필터를 조정합니다. 기본값은 Balanced, 5 ms입니다. 한 번 눌렀는데 여러 번 입력되는 증상이 있을 때만 관련 시간을 조금씩 늘리고, 문제가 없다면 기본 설정을 유지하십시오.

■ TAPPING

CONFIGURE -> FEATURE -> TAPPING에서 Mod-Tap/Layer-Tap의 탭·홀드 판정을 조정합니다. Tapping Term의 기본값은 200 ms입니다. 짧을수록 홀드가 빨리 걸리지만 빠른 타이핑이 의도치 않은 홀드로 판정될 수 있고, 길수록 안정적이지만 홀드가 늦게 들어옵니다.

- Permissive Hold: 다른 키를 눌렀다 뗄 때까지 탭·홀드 키를 계속 누르고 있으면 홀드로 판정합니다.
- Hold On Other Key Press: 다른 키를 누르는 순간 바로 홀드로 판정합니다. 더 빠르지만 굴려 치는 타건에서는 의도한 탭이 홀드가 될 수 있습니다.
- Retro Tapping: Term을 넘겨 눌렀더라도 그 사이 다른 키를 누르지 않았다면 키를 뗄 때 탭을 입력합니다.

■ MOUSE

정수 단위 정밀 입력은 usekb.cc의 고급 설정에서 제공합니다. 공식 VIA는 가장 가까운 프리셋을 표시하며 조회만으로 정밀 값을 바꾸지 않습니다. 휠 가속은 시간이 0이면 Off, 나머지는 목표 속도 기준으로 Mild/Strong을 표시합니다. 프리셋을 선택하면 그 설정으로 변경됩니다.

CONFIGURE -> FEATURE -> MOUSE에서 Mouse Key 동작을 조정합니다. 키맵에 Mouse Key가 없으면 입력에 영향을 주지 않습니다. 값들이 서로 영향을 주므로 한 번에 하나씩 조정하십시오.

- Cursor Acceleration: 시작 속도에서 최고 속도까지 가속하는 시간. Off면 고정 속도.
- Cursor Start Speed / Top Speed: 가속 시작/종료 시 한 스텝 이동 거리.
- Cursor Speed: Acceleration이 Off일 때 한 스텝 이동 거리.
- Cursor Steps Per Second: 초당 커서 이동 스텝 수.
- Wheel Rate: 초당 스크롤 스텝 수.
- Wheel Acceleration: 누르고 있는 동안 스크롤 가속 정도.

■ ROLLOVER / NKRO

CONFIGURE -> FEATURE -> NKRO에서 NKRO를 켜고 끕니다. 기본값은 꺼짐(6KRO)이고, 켜면 누른 키를 모두 보고합니다. 켠 뒤 오래된 BIOS/KVM이나 부팅 메뉴가 키보드를 읽지 못하면 다시 끄십시오.

■ LIGHTING

CONFIGURE -> LIGHTING에서 화면에 표시되는 조명 항목의 밝기, 효과, 색상을 설정합니다. 효과의 속도나 주기는 해당 효과에 제공되는 옵션으로 조정합니다.

Backlight Pulse를 지원하는 보드의 효과 이름은 다음과 같습니다.

- Steady
- Breathing
- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Breathing을 선택하면 Breathing Period(1~10)로 숨쉬기 주기를 조절하며, 값이 작을수록 빠릅니다. Pulse Speed는 Pulse에서만 표시되며 펄스 길이는 5 + 값 ms입니다(0은 5 ms, 255는 260 ms, 기본값 15는 20 ms). Hold 효과는 펄스 시간이 끝나도 해당 효과에서 새로 누른 물리 키가 남아 있으면 유지되며, 효과를 고르기 전부터 누르고 있던 키는 유지 대상이 아닙니다. 효과를 다시 고르거나 조명을 끄거나 절전에 들어가면 진행 중인 Pulse는 끝나며, 절전 중에 누른 키는 Pulse를 만들지 않습니다.

RGBLight 조명(Underglow, Badge, RGB LEDs)은 Effect 목록의 Twinkle 6 뒤에 같은 Pulse 효과 네 가지가 있습니다. Effect Speed는 이 네 효과에서만 표시되며 같은 방식으로 펄스 길이를 조절합니다. 일반 Breathing 1~4 등의 속도는 Effect의 번호로 선택하고, 지원 효과에서는 Velocikey로 입력 속도에 반응하게 할 수 있습니다.

- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Indicators는 Caps/Scroll/Num Lock 상태 표시입니다. 표시할 상태는 Indicator(여러 개면 Indicator 1, 2 …)에서 고릅니다. 0번 값은 표시 LED를 RGB 효과와 함께 쓰는 보드에서는 RGB Effect(효과가 그대로 보임), 전용 LED 보드에서는 Off입니다. 표시 대상과 화면에 제공되는 밝기·색상 옵션을 선택하십시오.

- RGB Effect
- Caps Lock
- Scroll Lock
- Num Lock

RGB Effect를 고른 LED는 일반 RGB 효과에 계속 참여합니다. Lock을 고른 LED는 해당 Lock이 켜졌을 때 그 Indicator의 Brightness와 Color를 사용합니다. Indicator-Only를 켜면 Lock이 꺼진 표시 LED는 어두워지고, RGB Effect LED는 계속 RGB 효과를 표시합니다. Brightness/Color는 Indicator 1/2/3마다 독립적으로 설정합니다.

■ SYSTEM

화면에 SYNC와 LINK가 제공되면 다음과 같이 사용합니다. EEPROM SYNC는 저장 설정을 동기화합니다. INPUT SYNC와 RGB SYNC는 양쪽을 각각 USB에 연결한 DUAL-HOST에서 입력 판정과 조명을 공유합니다. 세 설정은 독립적이며 기본 On입니다. 한쪽만 USB에 연결한 HOST-PEER에서는 INPUT SYNC와 RGB SYNC를 꺼도 입력과 조명 전달이 유지됩니다.

LINK는 High(460800 bps / 1 ms, 기본값), Medium(230400 bps / 2 ms), Low(115200 bps / 4 ms) 중 선택한 뒤 Apply합니다. 연결된 양쪽은 합의한 시점에 재부팅이나 USB 연결 해제 없이 함께 전환합니다. 공식 VIA 선택값은 적용 완료를 뜻하지 않으므로 실행·저장 속도와 결과는 usekb.cc Custom에서 확인하십시오.

SYSTEM -> SLEEP에서 RGB와 백라이트의 자동 절전을 따로 설정합니다. 키보드에 있는 조명의 항목만 표시됩니다.

- RGB Sleep, Backlight Sleep: 기본값은 On입니다. Off로 바꾸면 그 조명은 유휴 시간, USB 절전, 호스트 소실 어느 경우에도 꺼지지 않습니다.
- RGB Sleep Timeout, Backlight Sleep Timeout: 해당 절전이 On일 때만 보이며, 마지막 입력 뒤 1/3/5/10/30/60분 중 고릅니다. 기본값은 10분이고 토글을 꺼도 값은 보존됩니다.

절전은 조명 출력만 끄고 설정은 바꾸지 않습니다. 입력이나 정상적인 호스트 복귀로 다시 켜지지만, 사용자가 끈 조명을 자동으로 켜지는 않습니다. 백라이트가 잠금 표시등을 겸하는 키보드는 백라이트 절전 중 표시등도 꺼집니다.

SYSTEM -> BOOT의 Jump To BOOT를 켜면 부트로더 진입을 요청합니다. 실행 후 토글이 항상 꺼진 값으로 보이는 것이 정상입니다.

■ EEPROM CLEAN

세 확인 토글에는 시간 제한이 없습니다. 켠 토글을 끄면 해당 확인만 취소되며, 재부팅하면 확인 상태가 모두 지워집니다.

CONFIGURE -> SYSTEM -> EEPROM에서 세 확인 토글을 모두 켜면 저장된 키맵·매크로·모든 설정을 초기화하고 재시작합니다. 실행 전 VIA SAVE + LOAD로 백업하고 다른 설정을 기록하십시오. 스플릿은 정상 통신 중이면 양쪽이 합의하여 함께 초기화하고, 떨어진 유닛은 각각 로컬 CLEAN을 수행합니다.

This document guides you through using official VIA (https://usevia.app) directly. For general configuration, advanced editing, and live-updating status displays, https://usekb.cc and Help next to each menu are recommended.

■ Getting Started with Official VIA

Use the JSON inside the release ZIP that matches your keyboard.

1. Open https://usevia.app.
2. In SETTINGS, turn on Show Design tab.
3. In DESIGN -> Load Draft Definition, load the VIA JSON for this keyboard.
   If L/R files are provided, use the one matching the half currently connected via USB; when connecting both halves via USB separately, load both JSON files.
4. After allowing the connection with Authorize device in CONFIGURE, configure KEYMAP, LIGHTING, FEATURE, TAPDANCE, and SYSTEM.

When entering a keycode directly into a TAPDANCE input field, refer to via_keycodes.txt in the same folder. Official VIA SAVE + LOAD backs up only keymaps and macros and does not back up all menu settings, so record other settings separately.

A standard update preserves valid settings of the same storage format, but a storage format change or invalid saved data may trigger a reset. Reset.uf2 is not a standard update; it is a full-featured firmware that erases all current settings once on the first run after installation. Continue using it as is after the reset, and new settings are kept across reboots. Reinstalling the same file resets settings again. Follow readme.txt in the release ZIP for backup and recovery procedures.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION displays the keyboard firmware version in YYMMDDRn format and cannot be modified in VIA. Include this value when reporting an issue.

■ MATRIX TEST

Matrix Test in VIA shows physical matrix presses. Because host programs with VIA Raw HID access can query currently pressed matrix positions, use it on a trusted PC.

■ TAPDANCE

Configure TD0~TD7 in CONFIGURE -> TAPDANCE, then place the corresponding TD number on the desired key position in KEYMAP. Configured actions will not run until the TD key is placed on the actual keymap.

- On Tap: keycode sent on a quick tap
- On Hold: keycode sent when held down
- On Double Tap: keycode sent when tapped twice within Term
- Tap+Hold: keycode sent when tapped once and immediately held down
- Term: time window used to distinguish multiple input actions. In official VIA, select from 100~500ms in 20ms steps.

In Legacy mode, a slot with On Double Tap and Tap+Hold left blank sends a tap as soon as the key is released, and Term is used only for hold detection. When On Double Tap is set, it registers as soon as the second tap is released.

Official VIA edits only basic actions and Term in Legacy mode. For slots using advanced modes or unknown mode values, it displays only a notice to use usekb.cc and does not edit basic actions. Use https://usekb.cc to change input modes, set an independent hold time, or configure hold on other key press. Merely opening official VIA or loading a definition does not change a slot's mode or actions.

■ SOCD

In CONFIGURE -> FEATURE -> SOCD, assign two opposing keys (left/right, up/down) and select in Mode which key to send to the PC while both keys are held down together.

- Last Input: Sends only the key pressed later. When that key is released, the other key still held down is sent again immediately (Snap Tap). This is the default.
- Neutral: Sends neither key.
- First Input: Keeps the key pressed first.
- Left/Up Priority, Right/Down Priority: Sends the designated side regardless of press order.

Assign standard keys or modifier keys. Because evaluation is based on keys sent to the PC, it also applies to keys produced by Tap Dance or macros. Putting the same key in both slots of a pair will not work, and if two enabled pairs share the same valid key, neither pair will work. Key assignments in a disabled pair do not block other pairs. Some games and tournaments restrict SOCD use, so check the rules.

■ KKUK

Configured in CONFIGURE -> FEATURE -> KKUK. Holding down two or more standard keys periodically releases and re-presses the held key group according to the Delay/Repeat settings. For example, holding A, S, and D types "asdasdasd..." instead of normal "asdddd..." auto-repeat. It is not a string macro or matrix anti-ghosting feature. Only keys in an enabled, valid, non-overlapping SOCD pair are excluded from repeating; keys in disabled, invalid, or conflicting pairs are not excluded.

■ DEBOUNCE

Adjust the switch chatter filter in CONFIGURE -> FEATURE -> DEBOUNCE. The default is Balanced, 5 ms. Increase the relevant time slightly only if a single press registers multiple times, and keep the default setting if there is no issue.

■ TAPPING

Adjust tap/hold detection for Mod-Tap and Layer-Tap keys in CONFIGURE -> FEATURE -> TAPPING. The default Tapping Term is 200 ms. Shorter values trigger holds faster but may cause fast typing to register as unintended holds; longer values are more stable but delay hold activation.

- Permissive Hold: Registers a hold if you keep holding the tap/hold key while pressing and releasing another key.
- Hold On Other Key Press: Registers a hold immediately the moment another key is pressed. It responds faster, but rolling keystrokes may turn an intended tap into a hold.
- Retro Tapping: Sends a tap on release even if held past Term, provided no other key was pressed in the meantime.

■ MOUSE

Exact integer input is available in the advanced settings on usekb.cc. Official VIA displays the nearest preset and does not alter exact values merely by viewing them. For wheel acceleration, a time of 0 shows Off, while other values show Mild/Strong based on target speed. Selecting a preset changes the setting to that preset.

Adjust Mouse Key behavior in CONFIGURE -> FEATURE -> MOUSE. It has no effect on input unless Mouse Keys are placed on the keymap. Because these values interact with one another, adjust them one at a time.

- Cursor Acceleration: Time to accelerate from start speed to top speed. Fixed speed when Off.
- Cursor Start Speed / Top Speed: Movement distance per step at the start/end of acceleration.
- Cursor Speed: Movement distance per step when Acceleration is Off.
- Cursor Steps Per Second: Number of cursor movement steps per second.
- Wheel Rate: Number of scroll steps per second.
- Wheel Acceleration: Degree of scroll acceleration while held.

■ ROLLOVER / NKRO

Turn NKRO on or off in CONFIGURE -> FEATURE -> NKRO. The default is off (6KRO); when turned on, all pressed keys are reported. Turn it back off if an older BIOS/KVM or boot menu cannot read the keyboard after enabling it.

■ LIGHTING

In CONFIGURE -> LIGHTING, set the brightness, effect, and color for the lighting items shown on screen. Adjust effect speed or period using the options provided for that effect.

On boards that support Backlight Pulse, the effect names are as follows.

- Steady
- Breathing
- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

When Breathing is selected, Breathing Period (1~10) adjusts the breathing cycle, where smaller values are faster. Pulse Speed appears only for Pulse effects, and the pulse duration is 5 + value ms (0 is 5 ms, 255 is 260 ms, default 15 is 20 ms). Hold effects remain active after the pulse duration ends as long as a physical key newly pressed under that effect is still held; keys already held before selecting the effect are not kept active. Reselecting an effect, turning lighting off, or entering sleep ends any ongoing Pulse, and keys pressed during sleep do not generate a Pulse.

RGBLight lighting (Underglow, Badge, RGB LEDs) includes the same four Pulse effects after Twinkle 6 in the Effect list. Effect Speed appears only for these four effects and adjusts pulse duration in the same way. Speeds for standard effects such as Breathing 1~4 are selected by the number in Effect, and supported effects can use Velocikey to respond to typing speed.

- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Indicators show Caps/Scroll/Num Lock states. Select which state to display in Indicator (or Indicator 1, 2 … when multiple indicators exist). Value 0 is RGB Effect (shows the lighting effect as is) on boards that share indicator LEDs with RGB effects, or Off on boards with dedicated LEDs. Select the target state along with the brightness and color options shown on screen.

- RGB Effect
- Caps Lock
- Scroll Lock
- Num Lock

LEDs set to RGB Effect continue participating in general RGB effects. LEDs set to a Lock state use that Indicator's Brightness and Color while the corresponding Lock is active. When Indicator-Only is enabled, indicator LEDs whose Lock is off stay dark, while RGB Effect LEDs continue displaying RGB effects. Brightness/Color are configured independently for each of Indicator 1/2/3.

■ SYSTEM

When SYNC and LINK are shown on screen, use them as follows. EEPROM SYNC synchronizes saved settings. INPUT SYNC and RGB SYNC share input evaluation and lighting in DUAL-HOST mode when both halves are connected via USB separately. All three settings are independent and default to On. In HOST-PEER mode with only one half connected via USB, key input and lighting forwarding continue even if INPUT SYNC and RGB SYNC are turned off.

For LINK, select High (460800 bps / 1 ms, default), Medium (230400 bps / 2 ms), or Low (115200 bps / 4 ms) and then Apply. Connected halves switch together at an agreed point without rebooting or disconnecting USB. Because the selected value in official VIA does not indicate that application has completed, check active/saved speeds and results in usekb.cc Custom.

In SYSTEM -> SLEEP, configure automatic sleep separately for RGB and backlight. Only items for lighting present on the keyboard are shown.

- RGB Sleep, Backlight Sleep: Default to On. When set to Off, that lighting will not turn off due to idle time, USB suspend, or host loss.
- RGB Sleep Timeout, Backlight Sleep Timeout: Shown only when the corresponding sleep toggle is On; select from 1/3/5/10/30/60 minutes after the last input. The default is 10 minutes, and the value is preserved even when the toggle is turned off.

Sleep turns off lighting output only without changing saved settings. Lighting turns back on upon key input or normal host resume, but lighting turned off by the user is not turned on automatically. On keyboards where the backlight also serves as a lock indicator, the indicator turns off during backlight sleep as well.

Turning on Jump To BOOT in SYSTEM -> BOOT requests bootloader entry. It is normal for the toggle to always appear off after execution.

■ EEPROM CLEAN

The three confirmation toggles have no time limit. Turning off an enabled toggle cancels only that confirmation, and rebooting clears all confirmation states.

Turning on all three confirmation toggles in CONFIGURE -> SYSTEM -> EEPROM resets saved keymaps, macros, and all settings and restarts the keyboard. Back up with VIA SAVE + LOAD and record other settings before running it. On split boards communicating normally, both halves agree to reset together; disconnected halves perform a local CLEAN independently.
