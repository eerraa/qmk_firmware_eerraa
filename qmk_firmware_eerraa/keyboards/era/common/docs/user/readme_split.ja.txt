■ ファームウェアアップデート

ご使用中のキーボードに合ったファームウェア ZIP を使用し、分割型キーボードの左ユニットと右ユニットに必ず同じ .uf2 ファイルをインストールしてください。異なるファームウェアバージョンの組み合わせはサポートしていません。

片側ずつ次の手順を進めます。

1. ユニットを Bootloader モードに切り替えます。
   - キーボード設定画面：SYSTEM -> BOOT -> Jump To BOOT
   - キーマップに配置した QK_BOOT キー
   - 書き込むユニットの一番左上の物理キーを押したまま USB 接続（Bootmagic）
   - 該当ユニットの Reset ボタンを素早く二回押すか、RST と GND を素早く二回短く接続（各接続のあいだは完全に離す）
2. PC に RPI-RP2 ドライブが表示されたら、通常ファームウェアの .uf2 をコピーします（完了後に自動再起動）。
3. 反対側のユニットにも同じ .uf2 ファイルをインストールし、各ユニットの SYSTEM -> VERSION でバージョンを確認します。

以前のファームウェアは Bootmagic 進入時に設定が初期化されることがあるため、各ユニットの最初のアップデートには VIA BOOT または Reset 二回押しを使用してください。通常のアップデートでは同じ保存形式の有効なキーマップ・マクロ・設定が維持されますが、保存形式の変更や無効な保存データは進入方法に関係なく初期値にリセットされることがあります。アップデートや EEPROM CLEAN の前に VIA SAVE + LOAD でキーマップをバックアップしておいてください。通常のアップデートに Reset.uf2 を使用しないでください。

■ 設定復旧の初期化

同じ ZIP の Reset.uf2 は通常ファームウェアのすべての機能を含んでいます。インストール後の初回起動時のみ現在の設定（キーマップ・マクロ・ユーザー設定）をすべて初期化し、通常ファームウェアを入れ直さずにそのままキーボードとして使用できます。可能であれば先にバックアップしてください。

スプリットケーブルを外し、各ユニットを別々に初期化してください。片側だけ初期化すると、初期化していない反対側が以前の設定を復元してしまうことがあります。

1. 各ユニットを Bootloader に入れて同じ Reset.uf2 をコピーします。
2. 各ユニットの初期化が終わり、キーボードとして再接続されるまで待ちます。
3. 両側とも終わったらスプリットケーブルを再接続し、新しく設定して使用します。

以降の再起動では新しく保存した設定が維持され、同じ Reset.uf2 を再度インストールすると再び一回初期化されます。転送の中断はインストール完了ではないため、再アップロードが必要です。初期化中に電源が切れた場合は再試行され、正常な使用が始まらない場合は該当ユニットのハードウェア Bootloader 進入方法で同じ Reset.uf2 を再アップロードしてください。チップ全体やブートローダーは消去せず、セキュア消去や物理的なフラッシュ故障の修復は保証しません。

■ キーボード設定

キーボード設定と高度な機能には https://usekb.cc と各設定メニュー横の Help を推奨します。Tap Dance の高度な入力モードとホールド設定は usekb.cc でサポートしており、公式 VIA は基本動作と Term のみを編集します。

公式 VIA（https://usevia.app）を直接使用するには、配布 ZIP の usevia.app/usevia.txt で左/右 Draft Definition の読み込み、スプリット専用設定、リンク・同期 STATUS 表示を確認してください。
