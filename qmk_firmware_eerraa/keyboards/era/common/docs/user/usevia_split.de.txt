======================================================================
Split Official VIA Guide
======================================================================

Dieses Dokument dient als Anleitung für die direkte Nutzung des offiziellen VIA (https://usevia.app). Für allgemeine Einstellungen, erweiterte Bearbeitung und automatisch aktualisierte Statusanzeigen werden https://usekb.cc sowie Help neben dem jeweiligen Menü empfohlen.

■ Erste Schritte mit dem offiziellen VIA

Verwenden Sie die zur Tastatur passende JSON-Datei aus der Release-ZIP.

1. Rufen Sie https://usevia.app auf.
2. Aktivieren Sie unter SETTINGS die Option Show Design tab.
3. Laden Sie unter DESIGN -> Load Draft Definition die VIA-JSON der Hälfte, die aktuell per USB verbunden wird. Die L-Datei ist für die linke Hälfte, die R-Datei für die rechte Hälfte.
4. Wenn Sie unter DUAL-HOST beide Hälften jeweils per USB verbinden, laden Sie beide L/R-JSON-Dateien.
5. Richten Sie unter CONFIGURE die Bereiche KEYMAP, LIGHTING, FEATURE, TAPDANCE und SYSTEM ein.

Wenn Sie einen Keycode direkt in ein TAPDANCE-Eingabefeld eintragen, beachten Sie via_keycodes.txt im selben Ordner. Um Ihre Tastenbelegung zu sichern, nutzen Sie SAVE + LOAD in VIA.

Ein reguläres Update behält gültige Einstellungen desselben Speicherformats bei, doch eine Änderung des Speicherformats oder ungültige Speicherdaten können ein Zurücksetzen auslösen. Reset.uf2 ist kein reguläres Update, sondern eine vollwertige Firmware, die beim ersten Start nach der Installation einmalig alle aktuellen Einstellungen löscht. Nach dem Zurücksetzen wird sie direkt weiterverwendet, und neue Einstellungen bleiben auch nach einem Neustart erhalten. Eine erneute Installation derselben Datei setzt die Einstellungen wieder zurück. Sie müssen das Kabel trennen und beide Hälften zurücksetzen. Folgen Sie für Sicherung und Wiederherstellung der Datei readme.txt in der Release-ZIP.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION zeigt die Firmware-Version der aktuell per USB verbundenen Hälfte im Format YYMMDDRn an und kann in VIA nicht geändert werden. Beide Hälften müssen dieselbe Version verwenden.

■ MATRIX TEST

Matrix Test in VIA zeigt physische Matrix-Tastendrücke der aktuellen USB-Hälfte an. Da Host-Programme mit Zugriff auf VIA Raw HID aktuell gedrückte Matrix-Positionen abfragen können, sollten Sie die Funktion nur an einem vertrauenswürdigen PC verwenden.

■ TAPDANCE

Konfigurieren Sie TD0~TD7 unter CONFIGURE -> TAPDANCE und platzieren Sie anschließend unter KEYMAP dieselbe TD-Nummer an der gewünschten Position. Bevor die TD-Taste in der tatsächlichen Tastenbelegung platziert ist, wird die eingestellte Aktion nicht ausgeführt.

- On Tap: Keycode beim kurzen Tippen
- On Hold: Keycode beim gedrückt Halten
- On Double Tap: Keycode beim zweimaligen Tippen innerhalb von Term
- Tap+Hold: Keycode beim einmaligen Tippen und anschließendem gedrückt Halten
- Term: Zeitfenster zur Unterscheidung mehrerer Eingabeaktionen. Im offiziellen VIA wählen Sie zwischen 100~500ms in 20ms-Schritten.

Sind im Legacy-Modus On Double Tap und Tap+Hold bei einem Slot leer, wird das Tippen sofort beim Loslassen der Taste ausgelöst und Term dient nur zur Erkennung des Haltens. Ist On Double Tap belegt, erfolgt die Eingabe beim Loslassen des zweiten Tippens.

Das offizielle VIA bearbeitet nur Grundaktionen und Term im Legacy-Modus. Bei Slots mit erweitertem Modus oder unbekanntem Moduswert zeigt es lediglich einen Hinweis auf usekb.cc an und bearbeitet auch die Grundaktionen nicht. Nutzen Sie https://usekb.cc für das Ändern des Eingabemodus, eine unabhängige Haltezeit sowie die Einstellung für Halten beim Drücken einer anderen Taste. Allein das Öffnen des offiziellen VIA oder das Laden einer Definition ändert weder den Modus noch die Aktionen eines Slots.

■ SOCD

Weisen Sie unter CONFIGURE -> FEATURE -> SOCD zwei entgegengesetzte Tasten (links/rechts, oben/unten) zu und wählen Sie unter Mode aus, welche Taste an den PC gesendet wird, während beide Tasten gemeinsam gedrückt gehalten werden.

- Last Input: Sendet nur die später gedrückte Taste. Wird diese Taste losgelassen, wird die andere noch gedrückt gehaltene Taste sofort wieder eingegeben (Snap Tap). Dies ist der Standardwert.
- Neutral: Sendet keine der beiden Tasten.
- First Input: Behält die zuerst gedrückte Taste bei.
- Left/Up Priority, Right/Down Priority: Sendet unabhängig von der Reihenfolge des Drückens die festgelegte Seite.

Weisen Sie den Tasten reguläre Tasten oder Modifier-Tasten zu. Da die Auswertung anhand der an den PC gesendeten Tasten erfolgt, gilt sie auch für Tasten, die von Tap Dance oder Makros ausgelöst werden. Wird in beide Felder eines Paares dieselbe Taste eingetragen, funktioniert es nicht; teilen sich zwei aktivierte Paare dieselbe gültige Taste, funktionieren beide Paare nicht. Die Tastenzuweisung eines deaktivierten Paares blockiert andere Paare nicht. Da unter DUAL-HOST beide Hälften separat an den PC senden, müssen sich beide Tasten eines Paares auf derselben Hälfte befinden, damit SOCD greift. Da einige Spiele und Turniere die Nutzung von SOCD einschränken, prüfen Sie bitte das jeweilige Regelwerk.

■ KKUK

Wird unter CONFIGURE -> FEATURE -> KKUK verwendet. Werden zwei oder mehr reguläre Tasten gedrückt gehalten, wird die gedrückte Tastengruppe entsprechend den Einstellungen für Delay/Repeat periodisch losgelassen und erneut gedrückt. Werden beispielsweise A, S und D gedrückt gehalten, wird statt der üblichen automatischen Wiederholung „asdddd...“ die Folge „asdasdasd...“ eingegeben. Dies ist weder ein Textmakro noch eine Funktion gegen Matrix-Ghosting. Nur Tasten eines aktivierten, gültigen und sich nicht mit einem anderen Paar überschneidenden SOCD-Paares sind von der Wiederholung ausgenommen; Tasten deaktivierter, ungültiger oder in Konflikt stehender Paare werden nicht ausgenommen.

■ DEBOUNCE

Passen Sie unter CONFIGURE -> FEATURE -> DEBOUNCE den Filter gegen Schalterprellen an. Der Standardwert ist Balanced, 5 ms. Erhöhen Sie die entsprechende Zeit nur dann schrittweise, wenn ein einzelner Tastendruck mehrfach ausgelöst wird, und behalten Sie die Standardeinstellung bei, wenn keine Probleme auftreten.

■ TAPPING

Passen Sie unter CONFIGURE -> FEATURE -> TAPPING die Tipp-/Halte-Erkennung für Mod-Tap/Layer-Tap an. Der Standardwert für Tapping Term beträgt 200 ms. Kürzere Werte lösen das Halten schneller aus, können aber schnelles Tippen unbeabsichtigt als Halten werten; längere Werte sind stabiler, verzögern jedoch das Auslösen des Haltens.

- Permissive Hold: Wertet die Eingabe als Halten, wenn die Tipp-/Halte-Taste weiter gedrückt gehalten wird, bis eine andere Taste gedrückt und wieder losgelassen wurde.
- Hold On Other Key Press: Wertet die Eingabe sofort in dem Moment als Halten, in dem eine andere Taste gedrückt wird. Reagiert schneller, kann jedoch beim rollenden Tippen ein beabsichtigtes Tippen zum Halten machen.
- Retro Tapping: Gibt beim Loslassen der Taste ein Tippen ein, selbst wenn Term überschritten wurde, sofern in der Zwischenzeit keine andere Taste gedrückt wurde.

■ MOUSE

Eine präzise ganzzahlige Eingabe steht in den erweiterten Einstellungen auf usekb.cc zur Verfügung. Das offizielle VIA zeigt die nächstgelegene Voreinstellung an und verändert präzise Werte nicht allein durch das Anzeigen. Bei der Mausradbeschleunigung wird bei einer Zeit von 0 Off angezeigt, andernfalls anhand der Zielgeschwindigkeit Mild/Strong. Durch Auswählen einer Voreinstellung wird diese Einstellung übernommen.

Passen Sie unter CONFIGURE -> FEATURE -> MOUSE das Verhalten von Mouse Key an. Befindet sich keine Mouse Key in der Tastenbelegung, hat dies keinen Einfluss auf die Eingabe. Da sich die Werte gegenseitig beeinflussen, sollten Sie sie einzeln nacheinander anpassen.

- Cursor Acceleration: Zeit für die Beschleunigung von der Startgeschwindigkeit bis zur Höchstgeschwindigkeit. Bei Off feste Geschwindigkeit.
- Cursor Start Speed / Top Speed: Bewegungsdistanz pro Schritt zu Beginn/Ende der Beschleunigung.
- Cursor Speed: Bewegungsdistanz pro Schritt, wenn Acceleration auf Off steht.
- Cursor Steps Per Second: Anzahl der Cursor-Bewegungsschritte pro Sekunde.
- Wheel Rate: Anzahl der Scrollschritte pro Sekunde.
- Wheel Acceleration: Stärke der Scrollbeschleunigung während des Gedrückthaltens.

■ ROLLOVER / NKRO

Schalten Sie NKRO unter CONFIGURE -> FEATURE -> NKRO ein oder aus. Standardmäßig ist es ausgeschaltet (6KRO); im eingeschalteten Zustand werden alle gedrückten Tasten gemeldet. Falls ein älteres BIOS/KVM oder Boot-Menü die Tastatur nach dem Einschalten nicht erkennt, schalten Sie es wieder aus.

■ LIGHTING

Passen Sie unter Per-Key RGB in CONFIGURE -> LIGHTING Helligkeit, Effekt, Geschwindigkeit und Farbe an. Badge legt die Rolle der Badge-LEDs fest.

- RGB-Only: Wendet den ausgewählten RGB-Effekt nur auf den Badge-Bereich an.
- Indicator: Legt fest, welcher Status unter RGB Effect / Caps Lock / Scroll Lock / Num Lock angezeigt wird. Bei RGB Effect zeigt das Badge den RGB-Effekt unverändert an.
- Indicator-Only: Nutzt den Badge-Bereich ausschließlich für die Lock-Anzeige. Reguläre RGB-Effekte werden nicht angezeigt, vorübergehende STATUS-Hinweise für Verbindung und Synchronisierung können jedoch angezeigt werden.
- Indicator Brightness / Indicator Color: Legt Helligkeit und Farbe der Lock-Anzeige fest.

■ SYSTEM

CONFIGURE -> SYSTEM umfasst die Split-spezifischen Bereiche SYNC und LINK sowie SLEEP und BOOT.

SYNC:
Alle drei Optionen sind standardmäßig auf On gesetzt und voneinander unabhängige Einstellungen.
- EEPROM SYNC: Synchronisiert gespeicherte Einstellungen beider Hälften. Solange der Synchronisierungsvorgang sichtbar ist, leuchtet STATUS blau. Dies ist keine Voraussetzung für INPUT SYNC oder RGB SYNC, sollte aber aktiviert bleiben, um Tastenbelegung und Einstellungen auf beiden Hälften synchron zu halten.
- INPUT SYNC: Teilt unter DUAL-HOST (beide Hälften mit dem PC verbunden) den Ebenenstatus und die Auswertung von Tasteneingaben, sodass beide Hälften wie eine einzige Tastatur arbeiten.
- RGB SYNC: Synchronisiert unter DUAL-HOST die Beleuchtung beider Hälften einschließlich reaktiver Effekte.
INPUT SYNC und RGB SYNC steuern den Umfang der gemeinsamen Nutzung unter DUAL-HOST. Unter HOST-PEER mit nur einer per USB verbundenen Hälfte bleibt die Weiterleitung von Eingaben und Beleuchtung auch dann erhalten, wenn diese beiden Einstellungen ausgeschaltet sind.

LINK:
- High: 460800 bps / 1 ms (Standardwert)
- Medium: 230400 bps / 2 ms
- Low: 115200 bps / 4 ms

Prüfen Sie die aktuelle aktive/gespeicherte Geschwindigkeit und das Ergebnis der Übernahme in der usekb.cc Custom-App. Der ausgewählte LINK-Wert im offiziellen VIA bedeutet nicht, dass die Übernahme abgeschlossen ist. Wählen Sie einen LINK-Wert und verwenden Sie anschließend Apply. Beide verbundenen Hälften schalten die Geschwindigkeit zu einem abgestimmten Zeitpunkt gemeinsam um, ohne die Tastatur neu zu starten oder die USB-Verbindung zu trennen.

TOMAK-TKL, TOMAK79H und TOMAK79S zeigen vorübergehende STATUS-Signale über den gesamten RGB-Bereich an.
- Grün 1-mal: Apply auf der Hälfte, die den Befehl empfangen hat, war erfolgreich. Dies schließt den Fall ein, dass aktive und gespeicherte Geschwindigkeit bereits übereinstimmen, bestätigt jedoch nicht das Speichern auf der anderen Hälfte.
- Rot 1-mal: Anfrage konnte nicht verarbeitet werden, wurde abgebrochen oder ist fehlgeschlagen.
- Kurzes Grün 2-mal auf beiden Hälften: Verbindung nach Geschwindigkeitsprüfung wiederhergestellt.
- Langes Rot 3-mal: Warnung vor Rückfall auf Low nach einem Verbindungsgeschwindigkeitsfehler. Tritt dies wiederholt auf, prüfen oder ersetzen Sie das Kabel. Allein anhand dieser Anzeige lässt sich die Ursache nicht eindeutig bestimmen.
- Blau: EEPROM-Synchronisierung läuft.
Während des RGB-Ruhezustands wird kein STATUS angezeigt. Benutzerdefinierte Farben regulärer Lock-Indikatoren und STATUS-Farben haben unterschiedliche Bedeutungen.

SLEEP:
RGB Sleep ist standardmäßig auf On gesetzt. Beim Ausschalten wird der gesamte automatische RGB-Ruhezustand deaktiviert, einschließlich Leerlaufzeit, USB-Ruhezustand und Verbindungsverlust zum Host. Die Zeiteinstellung ist nur bei On sichtbar; wählen Sie 1/3/5/10/30/60 Minuten nach der letzten Eingabe. Der Standardwert beträgt 10 Minuten. Der Zeitwert bleibt auch beim Ausschalten des Schalters erhalten.

BOOT:
Das Einschalten von Jump To BOOT fordert den Wechsel der aktuellen Hälfte in den Bootloader an. Es ist normal, dass der Wert nach der Ausführung immer als ausgeschaltet angezeigt wird.

■ EEPROM CLEAN

Für die drei Bestätigungsschalter gibt es kein Zeitlimit. Wird ein eingeschalteter Schalter wieder ausgeschaltet, wird nur diese Bestätigung zurückgenommen; ein Neustart löscht alle Bestätigungszustände.

Wenn Sie unter CONFIGURE -> SYSTEM -> EEPROM alle drei Bestätigungsschalter einschalten, wird CLEAN angefordert. Kommunizieren beide Hälften normal miteinander, stimmen sie sich ab, setzen Tastenbelegung, Makros und alle Einstellungen gemeinsam zurück und starten neu. Getrennte Hälften führen jeweils lokal ein CLEAN durch. Sichern Sie vor der Ausführung Ihre Tastenbelegung über VIA SAVE + LOAD.
